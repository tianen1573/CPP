###### 总结

> 递推(dp)是一个重要的算法范式，它将一个问题**分解为一系列更小的子问题**，并通过存储子问题的解来**避免重复计算**，从而大幅提升时间效率。

- **总之离不开找规律**，是一个**从前往后，自底向上**的算法。则我是由前面的元素推导出来的，我的出现和后面的元素没有关系，但我可能影响后面的元素。

- **是无后效性的，我被确定之后，不会再受后面的影响。**(1,2,4,8)(吃东西，后面有好吃的，但是也不能吐出来吧)

- 由小推大，由过去推现在，**并且，前面是后面的最优子结构**

- 和贪心的区别：贪心不关心前后，但dp需要前面的元素

###### 流程

例子：斐波那契数列，1 1 2 3 5 8 13 21 34 .......

> 1. 分析题目、找出规律、确认无后效性
> 2. 状态定义： f[i]代表的是什么：代表第i项的值
> 3. 状态转义方程：f[i]=f[i-1]+f[i-2]，i>=2
> 4. 状态初始化：和状态转移方程有关,和for起始位置有关 ：f[1]=1
> 5. 输出验证

三步走：状态定义、状态转移方程、状态初始化

状态定义：我的数组某个位置代表的是什么，只有明确元素的含义，才能推导出它和前面的元素的关系，才能找到规律，生成状态转移方程。

状态转移方程：根据规律，生成对应的状态转移方程

状态初始化：状态转移方程中，通常存在i-1、i-2等代码，这个时候有些元素就不能通过推导得出来，需要自己初始化。

##### 是什么+循环转递归

**自己调自己**

> 递归（英语：Recursion），在数学和计算机科学中是指在函数的定义中使用函数自身的方法，在计算机科学中还额外指一种通过重复将问题分解为同类的子问题而解决问题的方法。
>
> 递归的基本思想是某个函数直接或者间接地调用自身，这样原问题的求解就转换为了许多性质相同但是规模更小的子问题。求解时只需要关注如何把原问题划分成符合条件的子问题，而不需要过分关注这个子问题是如何被解决的。

###### 总结

**特点：自顶向下，触底反弹，越来越近**

递归（recursion）是一种算法策略，通过函数调用自身来解决问题。它**主要包含两个阶段**。

1. **递**：程序不断深入地调用自身，通常传入更小或更简化的参数，直到达到“终止条件”。
2. **归**：触发“终止条件”后，程序从最深层的递归函数开始逐层返回，汇聚每一层的结果。

而从实现的角度看，递归代码主要包含三个要素。

1. **终止条件**：用于决定什么时候由“递”转“归”。**合法边界内才能递归、走到目的地应该停止。**
2. **递归调用**：对应“递”，函数调用自身，通常输入更小或更简化的参数。**参数的变化应该越来越接近终止条件**。
3. **返回结果**：对应“归”，将当前递归层级的结果返回至上一层。**两个函数是独立的，调用自己总要为了点什么。**

###### 记忆化

> 8250,9069

**为什么需要记忆化？**

因为在递归的过程中，某些数据被重复求了很多次，非常浪费时间和空间，导致代码超时。

因此需要把求过的数据保存下来，只在第一次求的时候，进去递归求值，其他时候直接返回结果

**需要干什么：**

1. 需要定义一个数组存数据，一个参数是一维数组，两个是二维数组，......
2. 需要判断数据是第一次求还是其他时候求，根据题意可知，除了第一次都不为0，
   - 则判断如果是0，代表第一次求，不仅要求，还要保存下来
   - 否则，直接返回存储的数据 

~~~C++
// 9069
#include <bits/stdc++.h>
using namespace std;
long long n, m;
long long arr[12345];
long long fun(int x) {
	// 归 
	if(x == 1 || x == 2){
		return x - 1;
	}
	// 如果等于0，代表第一次求，需要求一下 
	if(arr[x] == 0){
		// 求的同时，还要记录下 
		arr[x] = fun(x - 1) + fun(x - 2); // 递 
	}
	// 返回 
    return arr[x];
}
int main() {
	cin >> n ;
	cout << fun(n);
}
~~~

~~~C++
// 总结
int josephus(int n, int k) {
  if (n == 1) return 0;
  if (k == 1) return n - 1;
  if (k > n) return (josephus(n - 1, k) + k) % n;  // k>n时，线性算法
  int res = josephus(n - n / k, k);
  res -= n % k;
  if (res < 0)
    res += n;  // mod n
  else
    res += res / (k - 1);  // 还原位置
  return res;
~~~

#### 二分思想

##### 二分的前提

- **按某种规则有序，进而能够舍弃一半**
- 找得到合法范围，以及能够画出来一个坐标系
  ![image-20241130140447596](%E5%9B%BE%E7%89%87/C3/image-20241130140447596.png)
- 三种关系，可让范围变化

##### 引入

> 给一个有序递增的数组arr，以及元素x，查找x在数组中的下标，不存在返回-1。

暴力写法：遍历数组进行查找，复杂度O(n)。

如果要查找n个元素的下标呢？暴力写法的复杂度就是O(n*n)了，会超时。

**可以发现：**

> 数组是有范围的，且是有序的。我们随机选择一个数组元素y，去和目标x比较，发现存在以下关系：
>
> - 相等时：找到了
> - 比x大时：y及y之后的都不可能是x，应该舍弃
> - 比x小时：y及y之前的都不可能是x，应该舍弃
>   ![image-20241129140210750](%E5%9B%BE%E7%89%87/C3/image-20241129140210750.png)

这就是二分思想：根据条件，舍弃一半，直到范围不合理。

#### 二分查找

##### 理论

- 范围是什么：元素的下标？还是元素的大小？

  - 元素大小：二分出来的不一定存在
  - 下标大小：二分出来的一定存在，因为下标是连续增长的

  所以范围指的就是：下标的范围，左端点l，右端点r。

- 如何二分：取范围的一半，也就是除2。根据大小，二分下标，m=(l+r)/2。

- 什么时候结束：不知道次数，只知道范围

  - 范围存在左右端点lr，l<=r代表范围合法
  - 不知道要找多少次，while循环

- 三种关系：大于、小于、等于

  - 等于：找到了，直接返回
  - 小于：m左边的不要了，左端点要改变，l=m+1
  - 大于：m右边的不要了，右端点要改变，r=m-1

- 注意事项：

  - m=(l+r)/2，m=(l+r)>>1，m=(r-l)/2+l。都是取一半，但第三章更好，前两个有时候会爆。

##### 重点

- 明确：查找->有序->二分，三步操作
- 查找：题目想要我们找一个满足特定条件的值
- 有序：能够画出坐标系图
- 二分：根据中间值和目标值的关系，可以舍弃一半，表现为，lr的变化
- 左右端点的变化：往右看，舍弃左边，左端点变化；往左看，舍弃右边，右端点变化
- 其他：范围，注意(l+r)是否爆int

~~~C++
// 二分查找是否存在 
#include<bits/stdc++.h>
using namespace std;
int arr[1000001];
int n,x; 
int binFind(int l, int r, int tar){
	while(l <= r){
		int mid = (l + r) / 2; // 取中间值 
		if(arr[mid] == tar){ // 找到了，返回下标 
			return mid; 
		}
		else if(arr[mid] > tar){ // 比目标值大，那mid~r都比tar大，重新在l~mid-1里面找，r发生变化 
			r = mid - 1;
		}
		else {// 比目标值小，那l~mid都比tar小，重新在mid+1~r里面找，l发生变化 
			l = mid + 1;
		}
	}
	return -1;
}
int main(){
	cin >> n;
	for(int i = 1; i <= n; i ++) cin >> arr[i];
	cin >> x;
	sort(arr+1,arr+1+n);
	cout << binFind(1, n, x);
	return 0;
}
~~~

#### 二分答案

> 通过分析可得，答案在一个范围里面，并且我们只能去一个个枚举，在这个范围里面去找一个最符合条件的值。
>
> 而且能够发现一个正相关图，也就是存在一个有序的“数组”，那我们就可以进行二分枚举。

##### 理论

- 能不能找到坐标系图？
- 范围是什么：通过题目信息，或者简单计算推断出答案的大致范围，l是最小值，r是最大值
- 如何二分：和二分查找不同，我们枚举的是答案的大小，m=(l+r)/2
- 什么时候结束：不知道次数，只知道范围

  - 范围存在左右端点lr，l<=r代表范围合法
  - 不知道要找多少次，while循环
- 两种关系：合理、不合理
  - 合理：记下来，再向更符合的方向找
  - 不合理：舍弃不合理的部分
- 如何判断合理：
  - 建议封装成函数：bool check(x)，检查x是否合理
  - 题目里肯定存在一个判断条件
- 注意事项：

  - m=(l+r)/2，m=(l+r)>>1，m=(r-l)/2+l。都是取一半，但第三个更好，前两个有时候会爆。

##### 重点

- 先分析出坐标系图，这样就能更好的找到"有序"。

- 注意横坐标表示的是什么，纵坐标表示的是什么！

- 确定好答案的范围：最小为多少，最大为多少。

- 一定要记住，二分的目标是答案，当我们确定好mid之后，对mid进行检查看是否满足。

- 把二分函数int bin(int ,int r)和检查函数bool check(int x)，拆分出来。直观且更容易实现。

~~~C++
			ans = mid;
			l = mid + 1; 
		}

			r = mid - 1;
		}
~~~
