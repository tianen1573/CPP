## 一、选择题答案与解析

---
### IP 地址基础（第 1–4 题）

**1.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | IP 地址唯一标识一台设备，相当于网络世界的**门牌号** |
| B | ❌ 身份证号侧重"身份"，门牌号侧重"位置"，数据包按地址投递更贴切 |
| C | ❌ 电话号码是通信联系，不是定位 |
| D | ❌ 邮政编码只到区域，不到具体设备 |

> 考点：IP 地址的本质作用——定位（逻辑地址）。

---

**2.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 16 位是 IPv4 前身的部分设计，不是标准 |
| B ✅ | IPv4 地址共 **32 位**二进制数 |
| C | ❌ 64 位不是 IP 地址标准 |
| D | ❌ 128 位是 IPv6 的长度 |

> 考点：IPv4 = 32 位（记忆点：4 段 × 8 位 = 32 位）。

---

**3.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | IPv4 写成 **4 段**十进制，每段 **0~255**（8 位二进制） |
| B | ❌ 8 段是 IPv6 的段数 |
| C | ❌ 每段最大 255，不是 999 |
| D | ❌ 段数、范围都错 |

> 考点：点分十进制的结构（4 段 × 0~255）。

---

**4.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 每段最多 255，256 非法 |
| B | ❌ 256 非法 |
| C ✅ | 192.168.1.1 每段都在 0~255 内，合法 |
| D | ❌ 用逗号分隔，不是点分十进制 |

> 考点：合法地址的书写规则（段值 0~255 + 点分隔）。

### IP 地址分类（第 5–8 题）

**5.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | 判断类别看**第一段**的取值范围 |
| B | ❌ 最后一段是主机号，不决定类别 |
| C | ❌ 所有 IPv4 都是 32 位 |
| D | ❌ 都是十进制书写 |

> 考点：分类依据 = 第一段数值范围。

---

**6.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 192 开头是 C 类 |
| B | ❌ 172 开头是 B 类 |
| C ✅ | **10** 开头在 A 类范围（1~126） |
| D | ❌ 224 开头是 D 类（组播） |

> 考点：A 类首段 1~126，`10.x` 是典型 A 类。

---

**7.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ A 类是 1~126 |
| B ✅ | **172** 落在 **128~191**，是 **B 类** |
| C | ❌ C 类是 192~223 |
| D | ❌ D 类是 224~239 |

> 考点：B 类首段 128~191。

---

**8.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 1~126 是 A 类 |
| B | ❌ 128~191 是 B 类 |
| C ✅ | **192~223** 是 C 类 |
| D | ❌ 224~239 是 D 类 |

> 考点：五类首段范围速记（A:1~126 / B:128~191 / C:192~223 / D:224~239 / E:240~255）。

### 特殊地址（第 9–11 题）

**9.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 127.0.0.1 不是公网服务器 |
| B ✅ | 回环地址 `127.0.0.1` 代表**本机自己**，用于本机自测 |
| C | ❌ 网关是连接网络的设备地址 |
| D | ❌ 广播地址是 255.255.255.255 |

> 考点：回环地址含义（127.x.x.x 都是回环，最常用 127.0.0.1）。

---

**10.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | **192.168.x.x** 是 C 类私有地址，局域网专用 |
| B | ❌ 162.105.x.x 是公网地址 |
| C | ❌ 223.5.5.5 是阿里公共 DNS，公网地址 |
| D | ❌ 8.8.8.8 是谷歌公共 DNS，公网地址 |

> 考点：私有三兄弟——10.x、172.16~31.x、192.168.x。

---

**11.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 私有地址不能在公网路由 |
| B | ❌ 私有地址不唯一，各局域网可重复使用 |
| C ✅ | 私有地址**只能在局域网内使用**，公网无法直接访问 |
| D | ❌ 私有与公有用途不同，区别明显 |

> 考点：私有地址的用途限制。

### IPv6（第 12–13 题）

**12.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 32 位是 IPv4 |
| B | ❌ 64 位不是标准 |
| C ✅ | IPv6 是 **128 位** |
| D | ❌ 没有 256 位的 IP 标准 |

> 考点：IPv6 = 128 位（解决 IPv4 地址枯竭）。

---

**13.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | IPv6 用 **8 段十六进制**，冒号 `:` 分隔 |
| B | ❌ 4 段是 IPv4 的段数 |
| C | ❌ 冒号不是点，8 段不是 4 段 |
| D | ❌ "6 段"是名字陷阱（IPv6 不是 6 段！） |

> 考点：IPv6 表示法（8 段、十六进制、冒号）。名字带 6 ≠ 6 段。

**14.** 答案 **B**

> 考点：域名结构（主机名.二级域名.顶级域名）与 DNS 的关系。

## 二、判断题答案与解析

**16.** 答案 **✅**（T）

每台联网设备都需要唯一 IP 地址，数据包才能准确送达——和寄快递需要收件人地址同理。

> 考点：IP 地址的必要性（门牌号类比）。

---

**17.** 答案 **❌**（F）

IPv4 每段范围是 **0~255**，256 超出范围，所以 `256.256.1.1` 是**非法地址**。

> 考点：段值上限 255（高频陷阱）。

---

**18.** 答案 **❌**（F）

`192.168.x.x` 是 **C 类私有地址**，只能在局域网内使用，公网无法直接访问。

> 考点：私有 vs 公网地址。

---

**19.** 答案 **✅**（T）

IPv6 正是为解决 IPv4 地址枯竭而生，地址长度 **128 位**，地址空间巨大。

> 考点：IPv6 的诞生原因与长度。

---

**20.** 答案 **❌**（F）

IP 地址是**逻辑地址**（软件层面分配）；硬件出厂烧录的是 **MAC 地址**（物理地址）。两者不是一回事。

> 考点：逻辑地址（IP） vs 物理地址（MAC）。
