| 代次 | 时期 | 逻辑元件 | 特点 |

### 2.2 硬件系统

#### （1）中央处理器（CPU）

- 组成：**运算器（ALU）** + **控制器（CU）** + **寄存器组** + 高速缓存（Cache）
- 功能：解释指令、处理数据、控制流程
- 主要指标：**主频**（GHz）、核心数、缓存大小
- ⭐ 常考：CPU 不包含——内存、硬盘、显卡

#### （2）GPU（图形处理器）- 显卡里面⭐

| 项目 | 说明 |
|------|------|
| **全称** | Graphics Processing Unit（图形处理器） |
| **特点** | 拥有**成百上千个并行计算核心**，擅长大规模并行计算 |
| **传统用途** | 图形渲染（游戏、3D 建模）、AI、云计算 |
| **AI 用途** | ⭐ 深度学习训练和推理的核心硬件。神经网络的大规模矩阵运算（乘法、卷积）在 GPU 上比 CPU 快几十倍 |
| **代表厂商** | NVIDIA（CUDA 生态）、AMD |
| **初赛考点** | GPU 不是 CPU，GPU 的核心是并行计算，AI 时代的重要算力基础 |

> ⭐ 通俗理解：CPU 是一个博士生，能解决各种复杂问题；GPU 是一万个小学生，只会简单计算但人多力量大——深度学习恰好就是大量简单计算（矩阵乘法），所以 GPU 特别适合。

#### （3）TPU（张量处理器）

| 项目 | 说明 |
|------|------|
| **全称** | Tensor Processing Unit（张量处理器） |
| **研发公司** | **Google**（谷歌），2016 年首次推出 |
| **设计目标** | 专门为**神经网络推理和训练**而设计的定制 ASIC 芯片 |
| **与 GPU 区别** | GPU 是通用并行计算芯片（也可用于图形渲染）；TPU 是**专用 AI 芯片**，只为张量运算而设计，效率更高 |
| **应用场景** | Google 搜索、翻译、AlphaGo、Google Cloud |
| **初赛了解** | 知道 TPU = Google 的 AI 专用芯片，与 GPU 区分开即可 |

> ⭐ **三者在 AI 中的角色：**
> - **CPU** → 调度、控制整体流程，不适合大规模并行计算
> - **GPU** → 深度学习训练的主力，目前最通用的 AI 加速器
> - **TPU** → Google 定制，专为 TensorFlow / 神经网络优化，效率极致

#### （4）存储器

```
       存储器
      ┌────┴────┐
     内存        外存
    ┌─┴─┐     ┌──┴──┐
   RAM  ROM  硬盘  光盘   U盘
   ↓     ↓
  可读写 只读
 断电丢失 不丢失
```

- **内存**（主存）：RAM（可读写，断电丢失）+ ROM（只读，断电不丢）
- **外存**（辅存）：硬盘、光盘、U盘——**断电不丢失**
- **缓存（Cache）**：位于 CPU 和内存之间，提高速度
- 存储速度：寄存器 > Cache > 内存 > 硬盘
- 单位造价越往右越便宜，容量越往右越大
- ![image-20260729134223928](%E5%9B%BE%E7%89%87/%E6%99%AE%E5%8F%8A%E7%BB%84%E5%88%9D%E8%B5%9B%E8%AF%BE%E4%BB%B6_%E7%AC%AC%E4%B8%80%E7%AB%A0/image-20260729134223928.png)
- ⚠️ 易错区分：**操作系统（Windows/Linux）存储在硬盘（外存）中**，开机时加载到内存（RAM）运行。ROM 中存储的是 **BIOS/UEFI 固件**（基本输入输出系统），负责开机自检和引导 OS。很多同学混淆「OS 存在 ROM 里」，注意区分（初赛常见陷阱）

## 第三节 信息的表示与存储（约 12 min）⭐ 重点+难点

### 3.1 数制基础

| 进制 | 基数 | 数码范围 | 后缀 |
|------|------|---------|------|
| 二进制 (B) | 2 | 0, 1 | `(1010)₂` 或 `1010B` |
| 八进制 (O/Q) | 8 | 0–7 | `(17)₈` 或 `17O` |
| 十进制 (D) | 10 | 0–9 | `(99)₁₀` 或 `99D` |
| 十六进制 (H) | 16 | 0–9, A–F | `(FF)₁₆` 或 `0xFF` |

### 3.2 进制转换方法

#### 🔄 R 进制 → 十进制（按权展开）
> 将各位数码乘以对应位权，再求和

- 例：`(1011.101)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 1×2⁻¹ + 0×2⁻² + 1×2⁻³`
- `= 8 + 0 + 2 + 1 + 0.5 + 0 + 0.125 = 11.625`
- 例：`(2AF)₁₆ = 2×16² + 10×16¹ + 15×16⁰ = 512 + 160 + 15 = 687`

#### 🔄 十进制 → R 进制（整数除 R 取余，小数乘 R 取整）

> ⭐ 初赛常考：除基取余法（整数部分），乘基取整法（小数部分）

例：`25` 转为二进制
```
25 ÷ 2 = 12 … 1  ↑
12 ÷ 2 = 6  … 0  │
 6 ÷ 2 = 3  … 0  │
 3 ÷ 2 = 1  … 1  │
 1 ÷ 2 = 0  … 1  │
结果：11001₂
```

#### 🔄 二、八、十六进制互转（三位/四位分组法）

- **二 → 八**：每 3 位二进制对应 1 位八进制
  - `(110 101 011)₂ = (653)₈`
- **二 → 十六**：每 4 位二进制对应 1 位十六进制
  - `(1101 0101 1011)₂ = (D5B)₁₆`
- **八 → 二**：每位八进制展开为 3 位二进制
- **十六 → 二**：每位十六进制展开为 4 位二进制

### 3.3 ⭐ 原码、反码、补码（高频考点）

> 计算机中的整数用 **补码** 存储

**假设字长为 n 位（通常为 8 位）：**

| | 正数 | 负数 |
|--|------|------|
| **原码** | 符号位 0 + 数值部分 | 符号位 1 + 数值部分 |
| **反码** | 同原码 | 符号位不变，数值位取反 |
| **补码** | 同原码 | 反码 + 1 |

**关键结论：**
- 正数的原码 = 反码 = 补码
- 负数的补码 = 反码 + 1
- **补码的补码 = 原码**
- ⭐ `-128` 的补码是 `10000000`（8 位机）

**例题（8 位）：**
- `+5` 的原码：`0000 0101`
- `-5` 的原码：`1000 0101` → 反码：`1111 1010` → 补码：`1111 1011`
- `-1` 的补码：`1111 1111`
- `0` 的补码：`0000 0000`（唯一表示）

### 3.4 存储单位与媒体文件大小计算

```
1 bit  = 1 个二进制位
1 Byte = 8 bit
1 KB   = 1024 B = 2¹⁰ B
1 MB   = 1024 KB = 2²⁰ B
1 GB   = 1024 MB = 2³⁰ B
1 TB   = 1024 GB = 2⁴⁰ B
1 PB   = 1024 TB = 2⁵⁰ B
```

> ⚠️ 注意区分：存储用 **1024**（二进制），硬盘厂商常用 **1000**（十进制）

### 3.5 ⭐ 媒体文件大小计算（初赛常考）

> 这类题通常给一个图片或视频的参数，让你算占多少内存。

**① 图片内存公式：**
```
大小（bit）= 宽度 × 高度 × 色彩位数
大小（Byte）= 宽度 × 高度 × 色彩位数 ÷ 8
```
- 例：`800 × 600` 分辨率，16 位色：`800 × 600 × 16 = 7,680,000 bit`，除 8 得 `960,000 Byte ≈ 937.5 KB`

**② 视频内存公式：**

```
大小（bit）= 宽度 × 高度 × 色彩位数 × 帧率 × 时长（秒）
```
- 例：一段 `1920 × 1080` 分辨率的 10 秒视频，24 位真彩色，30 帧/秒
  - `1920 × 1080 × 24 × 30 × 10 = 14,929,920,000 bit`
  -  ÷ 8 = `1,866,240,000 Byte`
  -  ÷ 1024 ÷ 1024 ≈ **1,780 MB ≈ 1.74 GB**（未压缩，由此可见原始视频为什么需要压缩编码）

> ⚠️ 结果单位为 bit，除以 8 得 Byte，再根据需要换算为 KB/MB

### 3.6 ⭐ 逻辑运算与位运算（高频考点）

| 运算 | 符号（C++） | 规则 |
|------|-----------|------|
| **与（AND）** | `&&` / `&` | 有 0 则 0，全 1 才 1 |
| **或（OR）** | `\|\|` / `\|` | 有 1 则 1，全 0 才 0 |
| **非（NOT）** | `!` / `~` | 0 变 1，1 变 0 |
| **异或（XOR）** | `^` | 相同为 0，不同为 1 |

> ⭐ 异或重要性质：`a ⊕ a = 0`，`a ⊕ 0 = a`，`a ⊕ b ⊕ b = a`

**⭐ 位运算例题（初赛常考）：**

| 运算 | 算式 | 过程 | 结果 |
|------|------|------|------|
| &（与） | `13 & 7` | `1101 & 0111 = 0101` | `5` |
| \|（或） | `13 \| 7` | `1101 \| 0111 = 1111` | `15` |
| ^（异或） | `13 ^ 7` | `1101 ^ 0111 = 1010` | `10` |
| ~（取反） | `~0` | 补码全 1 | `-1` |

## 第四节 计算机语言（约 4 min）

### 4.1 语言发展三阶段

```
第一代: 机器语言（二进制指令）→ 直接执行，计算机只看得懂这个
第二代: 汇编语言（助记符）     → 需汇编器转换
第三代: 高级语言（类自然语言） → 需编译/解释
```

### 4.2 编译 vs 解释

| | 编译型 | 解释型 |
|--|--------|--------|
| 过程 | 源程序 → 目标程序 → 执行 | 逐句翻译执行 |
| 速度 | 快（一次性翻译） | 慢（每次翻译） |
| 代表 | C/C++、Pascal、Go | Python、JavaScript、BASIC |
| 跨平台 | 需重新编译 | 安装解释器即可 |

### 4.3 编程范式

- **面向过程**：C、Pascal——以函数/过程为核心
- **面向对象**：C++、Java、Python——以对象/类为核心
  - 三大特征：封装、继承、多态

### 4.4 ⭐ 常见高级语言考点

- **C 语言**：1972 年，贝尔实验室，Dennis Ritchie
- **C++ 语言**：1983 年，Bjarne Stroustrup，C with Classes
- **Pascal 语言**：1971 年，Niklaus Wirth，结构化编程
- **Java**：1995 年，Sun 公司，跨平台（JVM）
- **Python**：1991 年，Guido van Rossum，解释型
- 所有高级语言程序都必须先编译成机器码才能运行。错误，解释性不需要编译。

### 5.2 网络拓扑结构

![image-20260729134431413](%E5%9B%BE%E7%89%87/%E6%99%AE%E5%8F%8A%E7%BB%84%E5%88%9D%E8%B5%9B%E8%AF%BE%E4%BB%B6_%E7%AC%AC%E4%B8%80%E7%AB%A0/image-20260729134431413.png)

**常见拓扑优缺点速记（≤20 字/种，贴合 CSP 考点）：**

| 拓扑 | 优点 | 缺点 |
|------|------|------|
| **星型** | 单点故障易定位 | 中心节点坏了全网瘫 |
| **总线型** | 布线少成本低 | 故障难排查、单点断全网 |
| **环型** | 传输稳定无冲突 | 单点断环、全网瘫痪 |
| **树型** | 扩展方便、层级清晰 | 根节点是瓶颈 |
| **网状** | 可靠性最高、冗余好 | 布线成本高、管理复杂 |

> ⭐ CSP 常考：**星型**（最常用）、**总线型**（早期以太网）、**环型**（令牌环网）。区分拓扑图识别题。

### 5.3 ⭐ OSI 七层模型 vs TCP/IP 四层模型

| 层 | OSI（七层） | TCP/IP（四层） | 常见协议 |
|----|------------|---------------|---------|
| 7 | 应用层 | 应用层 | HTTP, FTP, SMTP, DNS |
| 6 | 表示层 | ↓ | |
| 5 | 会话层 | ↓ | |
| 4 | 传输层 | 传输层 | **TCP**（可靠）, **UDP**（不可靠） |
| 3 | 网络层 | 网际层 | **IP**, ICMP, ARP |
| 2 | 数据链路层 | 网络接口层 | 以太网、Wi-Fi |
| 1 | 物理层 | ↓ | 网线、光纤、无线电波 |

> ⭐ 初赛常考：TCP 面向连接（三次握手）、UDP 无连接

### 5.4 ⭐ IP 地址

- IPv4：32 位，4 段十进制，例：`192.168.1.1`
- IPv6：128 位，16 字节，解决 IPv4 枯竭问题
- ⭐ 分类：
  - A 类：`1.0.0.0 – 127.255.255.255`（首位 0）
  - B 类：`128.0.0.0 – 191.255.255.255`（前两位 10）
  - C 类：`192.0.0.0 – 223.255.255.255`（前三位 110）
- ⭐ **特殊 IP**：`127.0.0.1`（回环地址/本机）、`192.168.x.x`（私有地址）

## 第六节 信息安全与计算机病毒（约 3 min）

### 6.1 计算机病毒

- **定义**：人为编制的具有破坏性的程序
- ⭐ **特征**：传染性、潜伏性、隐蔽性、破坏性、可触发性
- **分类**：蠕虫、木马、宏病毒、勒索软件等
- **传播途径**：网络、U 盘、邮件附件
- ⭐ **不要混淆**：病毒是程序（软件），不是硬件问题

### 6.2 网络安全基础

- **防火墙**：网络边界防护
- **加密技术**：对称加密 / 非对称加密（公钥+私钥）
- **数字签名**：验证身份 + 防篡改
- **认证技术**：密码、指纹、人脸、验证码

### 6.3 ⭐ 软件知识产权

- **自由软件**：可自由使用、修改、分发（GNU/GPL 协议）
- **开源软件**：源代码公开，但可能有限制
- **免费软件**：免费使用，源码不一定公开
- **共享软件**：试用期免费，需付费继续使用

## 第七节 常考数学基础（约 2 min）

### 7.1 排列组合入门

- **加法原理**：做一件事有 m 类方法 → 总方法数 = 各类方法数之和
- **乘法原理**：做一件事分 n 步 → 总方法数 = 各步方法数之积
- **排列**：`P(n,m) = n! / (n-m)!`（有序）
- **组合**：`C(n,m) = n! / (m!×(n-m)!)`（无序）
- ⭐ 常用性质：`C(n,m) = C(n, n-m)`，`C(n,0) = 1`

### 7.2 概率初步

- **古典概型**：事件概率 = 有利情况数 / 总情况数
- ⭐ 互斥事件、对立事件、独立事件（常见考点）
