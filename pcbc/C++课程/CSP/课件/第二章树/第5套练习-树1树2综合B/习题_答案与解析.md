## 二、判断题答案与解析（21–30）

**21.** 答案 **❌ F**

树的边数 = 节点数 **减** 1（n−1），不是加 1。关键陷阱词："加 1"。

> 考点：树的边数公式

**22.** 答案 **✅ T**

哈夫曼树中权值越小的叶子离根越远（这正是 WPL 最小的设计目标）。

> 考点：哈夫曼树权值与深度关系

**23.** 答案 **✅ T**

前缀表达式从右到左扫描（后缀从左到右，两者方向相反）。

> 考点：前缀表达式求值方向

**24.** 答案 **✅ T**

中序遍历严格递增 ⇔ 二叉搜索树，这是判定 BST 的依据。

> 考点：BST 判定（中序有序）

**25.** 答案 **❌ F**

满二叉树要求**每一层**都满；"叶子都在最后一层"只说明该树是"满的完全二叉树"（还差倒数第二层必须全满）。关键陷阱词："一定"。

> 考点：满二叉树定义（所有层都满）

**26.** 答案 **❌ F**

哈夫曼树不一定是完全二叉树（如权值 {7,5,2,4} 的哈夫曼树不是完全二叉树）。关键陷阱词："一定"。

> 考点：哈夫曼树 ≠ 完全二叉树

**27.** 答案 **❌ F**

BST 根节点不一定最大，最大值在右子树的最右叶子处。关键陷阱词："一定"。

> 考点：BST 性质（最大/最小值位置）

**28.** 答案 **✅ T**

前序 = 中序 ⟺ 每个节点都没有左子树 ⟺ 所有非叶子节点只有右子树。

> 考点：遍历序列性质（与选择题第 7 题呼应）

**29.** 答案 **✅ T**

`5 2 + 3 *`：2+5=7，7×3=21。

> 考点：后缀表达式求值

**30.** 答案 **✅ T**

二叉树中 n₀ = n₂ + 1，即度 2 节点数 = 叶子数 − 1。

> 考点：二叉树性质 n₀ = n₂ + 1

## 🧠 易错点速查

| 题号 | 考点 | 易错点 |
|:----:|------|--------|
| 1、21 | 树边数 | n−1 不是 n+1 |
| 2、14 | 高度/深度 | ⌊log₂n⌋ 要加 1 |
| 3 | 编码总位数 | 总位数 = WPL |
| 5 | BST 查找 | 比较次数含根节点 |
| 6、20 | 概念辨析 | 中序有序是 BST 专属；哈夫曼≠满二叉树 |
| 7、28 | 遍历序列 | 前序=中序 ⟺ 只有右子树 |
| 8 | 完全二叉树编号 | 父 ⌊i/2⌋，左 2i 右 2i+1 |
| 9 | BST 插入 | 升序插入退化为链 |
| 10、30 | n₀=n₂+1 | 别记反 |
| 15 | BST 判定 | 只看直接孩子不够，看中序 |
| 19 | 哈夫曼编码合法 | 同频等长 + 前缀码 + 高频短编码 |
| 25、26 | 特殊树区分 | 满 ⊂ 完全；哈夫曼与两者无包含关系 |
