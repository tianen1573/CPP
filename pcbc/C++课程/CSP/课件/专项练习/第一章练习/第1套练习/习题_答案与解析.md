### 计算机系统组成（第 4–7 题）

**4.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | GPU 有**成百上千个并行计算核心**，深度学习的大规模矩阵运算正是它擅长的 |
| B | ❌ GPU 是独立的图形处理器，不是 CPU 的一部分，二者分工不同 |
| C | ❌ 说反了：**CPU 擅长复杂顺序控制，GPU 擅长大规模并行计算** |
| D | ❌ GPU 最早用于图形渲染，但现在也是 **AI 计算的核心硬件** |

> 考点：CPU（博士生）vs GPU（一万个小学生）的定位，AI 时代 GPU 是训练主力。

---

**5.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 恰好完全反了 |
| B | ❌ Cache 比寄存器慢，硬盘比内存慢 |
| C ✅ | 速度从快到慢：**寄存器 > Cache > 内存 > 硬盘** |
| D | ❌ 寄存器最快、硬盘最慢，此顺序错误 |

> 考点：存储层次"越快越小、越慢越大"。容量顺序则反过来：硬盘 > 内存 > Cache > 寄存器。

---

**6.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 32 位指一次处理 **32 位（4 字节）** 数据，不是 32 字节 |
| B | ❌ 内存条容量是市场产品，与 CPU 寻址能力的上限无关 |
| C | ❌ 寻址空间指内存，不是硬盘 |
| D ✅ | 2³² = 4,294,967,296 字节 = **4GB**，这就是 32 位 CPU 最大寻址 4GB 的原因 |

> 考点：地址总线位数决定寻址能力。真题常考"32 位 vs 64 位机器区别是寻址空间不同"。

| A ✅ | 微信是**应用软件**（面向用户的程序） |
| B | ❌ Linux 是**操作系统**，属于系统软件 |
| C | ❌ 设备驱动程序属于**系统软件** |
| D | ❌ Dev-C++ 是编译器（**语言处理程序**），属于系统软件 |

> 考点：系统软件（OS、语言处理程序、驱动程序）与应用软件的划分，是真题选择题和判断题的双料考点。

### 信息的表示与存储（第 8–14 题）⭐ 重点

**8.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 见 B |
| B ✅ | `0x2F` = 2×16+15 = 47；(101111)₂ = 32+8+4+2+1 = 47，**两者相等** |
| C | ❌ 见 B |
| D | ❌ 进制不同也可以直接换算比较 |

> 考点：十六进制按权展开与二进制按权展开互化。真题常把两个不同进制的数放一起比较大小。

---

**9.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | 8 位补码 `10000000` 表示 **-128**（最小的负数） |
| B | ❌ 补码中 0 只有唯一表示 `00000000`，不存在 -0 |
| C | ❌ 8 位补码最大正数为 127，128 无法表示 |
| D | ❌ -127 的补码是 10000001 |

> 考点：8 位补码表示范围 -128 ~ +127；`10000000` 是 -128，这是高频考点。

---

**10.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 少乘了换算项或帧率算错 |
| B | ❌ 时长/色彩位数算错 |
| C ✅ | 1280×720×24×30×60 = 39,813,120,000 bit；÷8 = 4,976,640,000 B；÷1024³ ≈ **4.6 GB** |
| D | ❌ 见 C |

> 考点：视频大小 = 宽 × 高 × 色彩位数 × 帧率 × 时长（bit），÷8 得字节，再换 MB/GB。注意结果单位是 bit。

---

**11.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 500 是按 1000 进制（厂商算法）得到的结果，计算机按 1024 算 |
| B | ❌ 4GB÷8MB 不可能是 1024 |
| C | ❌ 同 A，按 1000 进制也不对 |
| D ✅ | 4GB = 4×1024 = 4096 MB；4096 ÷ 8 = **512 个** |

> 考点：存储容量按 **1024** 进制换算（1GB = 1024MB），警惕"厂商 1000 进制"陷阱。

---

**12.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 768KB 只有正确答案的 1/4（少乘了 4） |
| B | ❌ 2.25MB 是按 24 位色算的 |
| C | ❌ 1.5MB 是按 16 位色算的 |
| D ✅ | 1024×768×32 = 25,165,824 bit；÷8 = 3,145,728 B = **3 MB** |

> 考点：图片大小 = 宽 × 高 × 色彩位数（bit）。32 位色 = 4 字节/像素，可直接 1024×768×4 字节 = 3MB。

---

**13.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ `5 & 3` = (0101 & 0011) = 0001 = **1** |
| B | ❌ `5 ^ 3` = (0101 ^ 0011) = 0110 = **6** |
| C ✅ | `5 \| 3` = (0101 \| 0011) = 0111 = **7**，最大 |
| D | ❌ `~5` 按位取反（补码表示）= **-6** |

> 考点：与（全 1 才 1）、或（有 1 则 1）、异或（相同 0 不同 1）、取反（补码全 1 为 -1）。真题喜欢考"比较大小"或"异或交换"。

---

**14.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 66 是 'B' 的 ASCII 码 |
| B | ❌ 69 是 'E' 的 ASCII 码 |
| C | ❌ 71 是 'G' 的 ASCII 码 |
| D ✅ | 'A'=65，字母连续，'F' = 65+5 = **70** |

> 考点：`'A'=65`、`'a'=97`、`'0'=48`，大小写相差 32。记住基准值即可推算。

## 判断题答案与解析

**21.** 答案 **❌**（F）

把文件放入回收站并清空，操作系统只是把文件占用的硬盘空间**标记为"可覆盖"**，文件数据并未真正抹除；只要这块空间还没被新数据覆盖，就可以通过恢复软件找回。真题原题考过"送修前把文件放进回收站是否等于删除"。

> 考点：回收站/文件删除原理（标记删除 vs 物理擦除）。

---

**22.** 答案 **✅**（T）

冯·诺依曼体系结构的核心思想就是**存储程序**：把程序和数据都以二进制形式存入存储器，再由程序控制自动执行。这是现代计算机的基本原理。

> 考点：冯·诺依曼"存储程序 + 程序控制"。

---

**23.** 答案 **❌**（F）

32 位 CPU 指**字长 32 位**，即一次能处理 **32 位（bit）= 4 字节**的数据，不是 32 个字节。1 字节 = 8 位，32 位 = 4 字节。

> 考点：位（bit）与字节（Byte）的换算 + 字长的含义。

---

**24.** 答案 **✅**（T）

Python 是**解释型**语言，逐句翻译、逐句执行，不需要像 C/C++ 那样先整体编译成目标程序；跨平台时只要目标机器装了 Python 解释器即可运行。

> 考点：编译型（C/C++/Pascal）vs 解释型（Python/JavaScript/BASIC）。

---

**25.** 答案 **✅**（T）

计算机病毒是**人为编制的程序**（软件问题），具有传染性、潜伏性、隐蔽性、破坏性、可触发性，可通过网络、U 盘、邮件附件等传播。它不是硬件故障——"病毒是程序，不是硬件问题"是常考判断题。

> 考点：病毒的本质（程序/软件）与传播途径。

---

**26.** 答案 **✅**（T）

TCP（传输控制协议）是**面向连接**的可靠协议（三次握手建立连接）；UDP（用户数据报协议）是**无连接**的协议，不可靠但开销小、速度快。

> 考点：TCP vs UDP 的本质区别（面向连接/可靠性）。

---

**27.** 答案 **✅**（T）

域名从左到右级别从低到高，**cn 是顶级域名**，代表中国（国家代码顶级域名）。.com 商业、.edu 教育、.gov 政府、.org 非营利组织。

> 考点：顶级域名分类（.cn 中国、.com 商业、.edu 教育、.gov 政府）。

---

**28.** 答案 **✅**（T）

OSI 参考模型分 **7 层**（物理、数据链路、网络、传输、会话、表示、应用）；TCP/IP 参考模型分 **4 层**（网络接口、网际、传输、应用）。对应关系：TCP/IP 的应用层 ≈ OSI 的应用+表示+会话三层。

> 考点：OSI 七层 vs TCP/IP 四层模型。

---

**29.** 答案 **❌**（F）

**补码中 0 只有唯一表示**：全 0（00000000）。出现"两种 0"的是**原码**（+0：00000000 和 -0：10000000）。8 位补码反而多表示一个 -128。

> 考点：补码的优点之一就是 0 唯一，可多表示一个最小负数。

---

**30.** 答案 **❌**（F）

摩尔定律前半句对（晶体管数量约每 18–24 个月翻一番），但它是**经验规律**而非物理定律，随着工艺接近物理极限，增速正在放缓，"永远按此速度增长"的说法错误。

> 考点：摩尔定律的本质（经验观察，非永恒规律）。
