### 计算机的产生与发展（第 1–2 题）

**1.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 图灵奖是**计算机**领域最高奖，由 ACM 颁发；菲尔兹奖才是数学奖 |
| B ✅ | CCF 于 **1984 年**创办全国青少年计算机程序设计竞赛（NOI 的前身） |
| C | ❌ ENIAC（1946 年）采用**电子管**，晶体管是第二代元件 |
| D | ❌ 摩尔定律是晶体管数量约每 **18–24 个月**翻一番，不是 5 年 |

> 考点：NOI 创办时间（1984 年）是真题高频考点；奖项归属（图灵奖=计算机/ACM）与第 1 套第 1 题互补呼应。

**2.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 晶体管（第二代）不可能排在电子管（第一代）前面 |
| B | ❌ 超大规模集成电路（第四代）与集成电路（第三代）顺序颠倒 |
| C | ❌ 集成电路（第三代）不可能排在最前 |
| D ✅ | 正确顺序：电子管 → 晶体管 → 集成电路 → 超大规模集成电路 |

> 考点：四代计算机元件顺序，换场景（"整理清单"）考查，与第 1 套第 3 题（科技馆场景）互补。

### 计算机系统组成（第 3–6 题）

**3.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 内存属于**内存储器**；断电后数据丢失（RAM） |
| B | ❌ 计算机**缺少内存无法正常启动** |
| C ✅ | RAM（随机存取存储器）**断电后数据丢失**，这是它与 ROM 的本质区别 |
| D | ❌ ROM 是**只读**存储器，断电后数据不丢失 |

> 考点：RAM vs ROM（易失性 vs 非易失性）。真题原题考"断电后会丢失数据的存储器"。

---

**4.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 奔腾、酷睿是 CPU 的**型号**，不是厂家名（厂家是 Intel） |
| B | ❌ 不是硬盘型号 |
| C | ❌ 不是显示器型号 |
| D ✅ | "奔腾（Pentium）""酷睿（Core）""赛扬"都是 **CPU 型号** |

> 考点：CPU 型号识别（真题原题）。陷阱：把型号当厂家名。

---

**5.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 硬盘比内存**慢**得多 |
| B ✅ | **寄存器**位于 CPU 内部，是存取速度最快的存储部件 |
| C | ❌ Cache 容量比内存**小**（越大越慢、越小越快） |
| D | ❌ 外存（硬盘等）比内存慢 |

> 考点：存储层次速度排序的变式——从"排序"换成"判断正误"，考寄存器最快这一细节。

---

**6.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 接口只是连接点，不承担整体互连 |
| B ✅ | CPU、存储器、I/O 设备通过**总线**（数据总线、地址总线、控制总线）连接 |
| C | ❌ 控制线只是总线的一部分 |
| D | ❌ 系统文件不是硬件连接方式 |

> 考点：总线的作用（真题原题）。三类总线：数据、地址、控制。

### 信息的表示与存储（第 7–13 题）⭐ 重点

**7.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | 1 字节 = **8 位**（1 Byte = 8 bit） |
| B | ❌ 16 位是"字"的常见长度（16 位机） |
| C | ❌ 32 位是 4 字节 |
| D | ❌ 4 位是半字节（nibble） |

> 考点：字节与位的换算（真题原题）。bit 是最小单位，Byte 是基本单位。

---

**8.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 1600 是按 1000 进制且少算的干扰值 |
| B | ❌ 2000 是按 1000 进制算的 |
| C | ❌ 16000 是数量级错误 |
| D ✅ | 8GB = 8×1024 = 8192 MB；8192 ÷ 2 = **4096 张**（按 1024 进制） |

> 考点：存储容量 1024 进制换算（真题原题改编）。注意"大约"二字仍按 1024 进制。

---

**9.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 128KB 是 17 位地址线的寻址空间 |
| B | ❌ 1MB 是 20 位 |
| C | ❌ 1GB 是 30 位 |
| D ✅ | 2³² = 4,294,967,296 字节 = **4GB** |

> 考点：地址总线位数 → 寻址空间（2 的 n 次方）。与第 1 套第 6 题同考点不同问法（从"原因"换成"结果"）。

---

**10.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 162.105.135.27 合法（各段 0~255） |
| B | ❌ 192.168.0.1 合法（私有地址） |
| C ✅ | **256.256.129.1** 非法——每段取值范围是 **0~255**，256 超出范围 |
| D | ❌ 10.0.0.1 合法（私有地址） |

> 考点：IPv4 地址书写规则（真题原题）。陷阱：256 超出 0~255。

---

**11.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | -15 的 8 位补码：15 = 00001111，取反得 11110000，+1 得 **11110001** |
| B | ❌ 11110000 是 -15 的**反码**（未加 1） |
| C | ❌ 00001111 是 +15 的原码 |
| D | ❌ 11101111 是 -17 的补码 |

> 考点：负数补码 = 原码取反 + 1。与第 1 套第 9 题（给补码求值）互补：本套是给值求补码。

---

**12.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ 16MB 是 1024×2048×32 位算错的结果 |
| B | ❌ 4MB 少算了 |
| C ✅ | 2048×1024×32 bit ÷ 8 = 8,388,608 B = **8MB**（32 位色 = 4 字节/像素，2048×1024×4 = 8MB） |
| D | ❌ 2MB 是 2048×1024 不带色深的字节数的一半 |

> 考点：图片大小 = 宽 × 高 × 色彩位数（真题原题）。32 位色 = 4 字节/像素。

---

**13.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | `7 & 8` = (0111 & 1000) = 0000 = **0**（没有共同为 1 的位） |
| B | ❌ `7 \| 8` = 0111 \| 1000 = 1111 = 15 |
| C | ❌ `7 ^ 8` = 0111 ^ 1000 = 1111 = 15 |
| D | ❌ `~7` = 按位取反 = -8（补码） |

> 考点：位运算与/或/异或/取反。换问法：第 1 套考"最大"，本套考"为 0"。

## 判断题答案与解析

**21.** 答案 **❌**（F）

将文件放入回收站只是把文件移到"回收站"这个特殊文件夹，**并未从硬盘彻底删除**；即使清空回收站，数据也只是被标记为可覆盖，仍可能通过恢复软件找回。第 1 套第 21 题考"清空回收站"，本套考"放入回收站"，层级递进。

> 考点：回收站原理（标记删除 vs 物理删除）。

---

**22.** 答案 **❌**（F）

计算机存储数据的**基本单位是 Byte（字节）**；bit（位）是**最小单位**。1 Byte = 8 bit。

> 考点：bit 是最小单位、Byte 是基本单位（真题原题）。

---

**23.** 答案 **✅**（T）

1MB = 1024×1024 字节 = 2²⁰ 字节（计算机按 1024 进制）；厂商标称的 1MB 才是 1000×1000。

> 考点：1024 进制换算。

---

**24.** 答案 **❌**（F）

Linux 下可执行文件**没有默认扩展名**（靠权限位 x 判断可执行）；.exe 是 Windows 的约定。（真题原题）

> 考点：Linux vs Windows 可执行文件差异。

---

**25.** 答案 **✅**（T）

蓝牙和 Wi-Fi 都属于**无线局域网**（WLAN）技术；GPRS 是移动广域网，以太网是有线技术。

> 考点：无线通信技术分类（真题原题）。

---

**26.** 答案 **✅**（T）

搜索引擎中，给关键词加**双引号**表示**精确搜索**，只显示包含整个关键词的结果；减号表示排除。

> 考点：搜索引擎语法（真题原题）。

---

**27.** 答案 **✅**（T）

FTP（File Transfer Protocol，文件传输协议）用于**远程传输文件**；SMTP 发邮件、HTTP 浏览网页。

> 考点：FTP 用途（真题原题）。

---

**28.** 答案 **✅**（T）

**中断**是指 CPU 暂停当前程序的执行，转而处理紧急情况（如 I/O 请求），处理完再返回原程序继续执行。

> 考点：中断的定义（真题原题）。注意"中断"≠死机。

---

**29.** 答案 **✅**（T）

8 位补码 `10000000` = **-128**，这是补码能表示的最小负数（补码范围 -128 ~ +127）。

> 考点：补码表示范围（与第 1 套第 9 题、第 29 题呼应）。

---

**30.** 答案 **✅**（T）

CCF 于 2016 年发布公告，**从 2022 年开始 NOIP 不再支持 Pascal 语言**（C++ 成为主要语言）。

> 考点：NOI 系列赛事语言变更（真题原题）。
