### 程序基本常识：算法特征与复杂度（第 1–3 题）

**1.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | 有穷性是算法基本特征，必须在有限步内结束 |
| B | 确定性是算法基本特征，每步无歧义 |
| C | 可行性是算法基本特征，每步可实际完成 |
| D ✅ | 算法五大特征为：有穷、确定、可行、输入、输出，**没有"高效性"** |

> 考点：算法五大特征。

---

**2.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | O(log n) < O(n) < O(n²) < O(2ⁿ)，排序正确 |
| B | O(n) 应排在 O(log n) 之后，顺序错误 |
| C | O(n²) 不可能小于 O(n)，顺序错误 |
| D | 完全倒序 |

> 考点：常见复杂度大小排序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)。

---

**3.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | 两层循环嵌套，不可能是 O(n) |
| B | 没有二分/对数结构，不是 O(n log n) |
| C ✅ | 内层循环执行 i 次，总次数 = 0+1+2+…+(n−1) = n(n−1)/2 ≈ n²/2，即 O(n²) |
| D | 三层循环才是 O(n³)，这里只有两层 |

> 考点：嵌套循环复杂度相乘；内层依赖外层时仍为 O(n²)（约 n²/2）。

### 排序算法（第 8–10 题）

**8.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | 冒泡、选择、插入平均都是 O(n²) |
| B ✅ | 快排、归并、堆排平均都是 O(n log n)（"快归堆"） |
| C | 计数、桶、基数是线性复杂度排序 |
| D | 冒泡、选择是 O(n²) |

> 考点：平均 O(n log n) 的排序：快排、归并、堆排。

---

**9.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | 冒泡排序稳定 |
| B | 插入排序稳定 |
| C | 归并排序稳定 |
| D ✅ | 堆排序不稳定（不稳定：选择、快排、堆排"选快堆"） |

> 考点：排序稳定性：稳定（冒泡、插入、归并、计数、桶、基数），不稳定（选择、快排、堆排）。

---

**10.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | 数据已有序/逆序时，快排每次划分极端不平衡，退化到 O(n²) |
| B | O(n) 是理想最优情况才可能接近 |
| C | O(n log n) 是平均情况 |
| D | 指数复杂度，快排不会达到 |

> 考点：快排最坏 O(n²)，发生在数据有序/逆序时。

### 字符数组与字符串（第 13–15 题）

**13.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | strlen 不含 '\0'，不是 5 和 5 |
| B | sizeof 是数组大小含 '\0'，不是 6 和 6 |
| C | 顺序反了 |
| D ✅ | `strlen("hello") = 5`（不含 '\0'）；`sizeof("hello") = 6`（含 '\0'） |

> 考点：strlen 不含 '\0'，sizeof 包含整个数组（含 '\0'）。

---

**14.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | **错误说法**：`sizeof(s)` 是 string 对象占的内存，随平台实现而变（8/24/32/40 都可能），不是字符串长度！求长度用 `s.length()` |
| B | 正确，length() 返回长度 |
| C | 正确，find 未找到返回 string::npos |
| D | 正确，+= 可以拼接 |

> 考点：sizeof 不能用来求 string 长度（对象大小 ≠ 字符串长度）。

---

**15.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | "CSP" 是 3，"CSP-J" 不是 3 |
| B | 拼接后 5 个字符，不是 4 |
| C ✅ | "CSP" + "-J" = "CSP-J"，length() = 5 |
| D | 不是 6 |

> 考点：string 拼接与 length()。

### 链表（第 16–17 题）

**16.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | 链表随机访问是 O(n)，要遍历 |
| B ✅ | 已知位置时链表插入/删除只需改指针，O(1) |
| C | 数组插入要移动元素，O(n) |
| D | 链表节点分散存储，不要求连续 |

> 考点：顺序表 vs 链表：链表插入删除 O(1)、随机访问 O(n)；数组相反。

---

**17.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | 先改 p->next 会丢失原后继，插入断裂 |
| B | newNode 指向 p 会造成环，逻辑错误 |
| C | 同样会丢后继且成环 |
| D ✅ | 先让 newNode 指向原后继，再让 p 指向 newNode（先接后断） |

> 考点：链表插入操作的顺序（先处理新节点的 next，再改前驱的 next）。

### 栈与队列（第 18–19 题）

| B | 2 已被第一次 pop 弹出 |
| C | 3 已被第二次 pop 弹出 |
| D | 栈不为空，还剩 1 |

> 考点：栈 LIFO 的模拟执行。

---

**19.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | 队列是 FIFO，括号匹配用的是栈 |
| B | 表达式求值用的是栈 |
| C ✅ | 队列 FIFO，BFS 层序遍历用队列 |
| D | 递归调用底层用的是栈（函数调用栈） |

> 考点：栈 vs 队列的应用场景。

## 判断题答案与解析

**21.** 答案 **❌**

算法必须有**至少 1 个输出**（输出特征），输入可以是 0 个，输出不能是 0 个。

> 考点：算法五大特征之"输出"。

---

**22.** 答案 **✅**

计算时间复杂度时忽略常数，O(2n) = O(n)。

> 考点：复杂度计算规则——忽略常数。

---

**23.** 答案 **✅**

递归的空间复杂度 = 递归深度（每层递归占用额外栈空间）。

> 考点：递归的空间复杂度。

---

**24.** 答案 **❌**

`strlen("hello") = 5`，不包含末尾的 `'\0'`。6 是 `sizeof("hello")` 的结果。

> 考点：strlen 与 sizeof 的区别。

---

**25.** 答案 **✅**

快排平均 O(n log n)，但最坏情况（数据已有序/逆序）退化到 O(n²)。

> 考点：快排最坏情况。

---

**26.** 答案 **❌**

贪心只保证**局部最优**，不保证全局最优，需要通过反例或证明来判断。

> 考点：贪心的局限性。

---

**27.** 答案 **✅**

双向链表节点有 `prev`（前驱）和 `next`（后继）两个指针域，可双向遍历。

> 考点：双向链表结构。

---

**28.** 答案 **❌**

队列是**先进先出（FIFO）**；后进先出（LIFO）是栈。

> 考点：栈与队列的进出原则。

---

**29.** 答案 **❌**

`getline(cin, s)` 读取**一整行（含空格）**；遇到空格停止的是 `cin >> s`。

> 考点：cin >> 与 getline 的区别（经典陷阱）。

---

**30.** 答案 **✅**

已知位置时，链表插入/删除只需修改指针，时间复杂度 O(1)；O(n) 是"查找位置"的代价。

> 考点：链表的插入删除复杂度。
