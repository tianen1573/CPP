# 🖥️ 另一台电脑——初次配置指南

另一台电脑的 WSL 里 OpenClaw 是白纸，需要配以下东西才能跟这台同步。

---

## 1. SSH 密钥（拉仓库用）

```bash
# 在另一台电脑的 WSL 里执行
ssh-keygen -t ed25519 -C "qlz1573@qq.com"
cat ~/.ssh/id_ed25519.pub
```

复制输出的公钥 → 打开 https://github.com/settings/keys → **New SSH key** → 粘贴保存

```bash
# 配置 SSH
echo 'Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes' > ~/.ssh/config

# 验证
ssh -T git@github.com
```

---

## 2. Git 配置

```bash
git config --global user.name "qiu"
git config --global user.email "qlz1573@qq.com"
```

---

## 3. 拉 CLAW 仓库到桌面

```bash
cd /mnt/c/Users/qlz15/Desktop
git clone git@github.com:tianen1573/CPP.git
```

以后更新就是：
```bash
cd /mnt/c/Users/qlz15/Desktop/CPP
git pull
```

---

## 4. 安装 OpenClaw 技能

这台电脑上已装好的技能，另一台需要重新安装：

- algorithm-mentor — 苏格拉底算法教学
- algorithm-solver — 算法题解
- exam-paper — 试卷生成
- exam-question-generator — 模拟题生成
- teaching-materials — 教学文档/课件生成
- teaching-presentation — 教案转PPT

在另一台电脑的 OpenClaw 里输入对应的触发词即可安装，或直接去 ClawHub 搜索下载。
