## 背景

- 出题/课件规范已更新，规则源已同步进仓库 `CLAW/龙虾同步/`（`AGENTS.md`、`偏好记录.md` 均为最新版，含硬规则：**每次在 `CLAW/2026/` 下新建文件夹后必须更新 `快速查找.md`**）
- 但 OpenClaw 每次启动只注入本机 `~/.openclaw/workspace/` 里的文件，仓库里的副本**不会自动生效**
- 所以需要把这两个文件链接/拷贝到本机 workspace，让规则进入"大脑"

## 执行步骤

### 1. 找到本机 CPP 仓库路径

```bash
ls -d /mnt/c/Users/*/Desktop/CPP 2>/dev/null
```

选**含有 `CLAW/龙虾同步/` 目录**的那个，记为 `$CPP`（命令中用实际路径替换 `$CPP`）。

### 2. 备份现有文件（防呆，不覆盖丢失）

```bash
cd ~/.openclaw/workspace
for f in AGENTS.md 偏好记录.md; do
  [ -f "$f" ] && [ ! -L "$f" ] && cp "$f" "$f.bak-20260803"
done
```

### 3. 建立软链接（推荐：以后每次 pull 自动拿到最新版）

```bash
ln -sf "$CPP/CLAW/龙虾同步/AGENTS.md" ~/.openclaw/workspace/AGENTS.md
ln -sf "$CPP/CLAW/龙虾同步/偏好记录.md" ~/.openclaw/workspace/偏好记录.md
```

> 若因沙箱/权限 symlink 失败，退回 `cp` 拷贝（注意：拷贝版不会自动跟随仓库更新）。

### 4. 检查/补充本机 TOOLS.md（**只追加，不要覆盖原内容**）

TOOLS.md 需包含两条：
- 本机 CPP 仓库路径：`/mnt/c/Users/<本机Windows用户>/Desktop/CPP/`
- 提示：出题/课件/试卷/刷题网页偏好规范见工作区 `偏好记录.md`

缺失就用 edit 工具补上（保留原有技术配置）。

### 5. 验证

```bash
grep -c "快速查找" ~/.openclaw/workspace/AGENTS.md        # 应 ≥ 1
ls -l ~/.openclaw/workspace/AGENTS.md                      # 确认是链接或新文件
grep -n "硬规则\|强制步骤" ~/.openclaw/workspace/偏好记录.md
```
