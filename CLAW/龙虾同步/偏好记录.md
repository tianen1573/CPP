## 一、课件出稿规范

### 基本原则
- **默认只出老师版**，不要求不出学生版
- 不要求不出 HTML 可视化工具
- 出课件时配 SVG 图（Node.js 生成），按理解出图即可

### 老师版内容
- 含考试信息（如 CSP-J / GESP）
- 含时间安排（≈min）
- 含目录
- 含附录（板书建议、讲解节奏）
- 含真题精练及解析

### 文件夹命名
- `{日期}_{序号}_{主题描述（≤10字）}`
- 示例：`7_30_1_树的理论`

### 文件命名
| 类型 | 命名 |
|------|------|
| 课件 | `课件_老师.md`、`课件_学生.md` |
| 习题 | `习题_老师.md`、`习题_学生.md`、`习题_答案.md` |
| 刷题网页 | `刷题.html` |
| 可视化工具 | `{主题}可视化工具.html` |

### 存放位置
- 所有文件在 `桌面/CPP/CLAW/2026/{日期}_{序号}_{主题}/` 下
- 图片在内部 `图片/` 子目录
- 出完课件要更新 `快速查找.md`

### Obsidian 配置说明

| 文件 | 作用 |
|------|------|
