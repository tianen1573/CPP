## 三、程序阅读题（共 2 题，每题 10 分，共 20 分）

**16.** 阅读以下程序，输出结果是什么？

```cpp
#include <iostream>
using namespace std;
int main() {
    int s = 0;
    for (int i = 1; i <= 5; i++) {
        s += i;
    }
    cout << s << endl;
    return 0;
}
```
A. 10
B. 15
C. 20
D. 25

---

**17.** 阅读以下程序，输出结果是什么？

```cpp
#include <iostream>
using namespace std;
int main() {
    int a[5] = {3, 7, 2, 9, 5};
    int mx = a[0];
    for (int i = 1; i < 5; i++) {
        if (a[i] > mx) mx = a[i];
    }
    cout << mx << endl;
    return 0;
}
```
A. 3
B. 7
C. 5
D. 9
