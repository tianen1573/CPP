## 一、二叉树基础概念

### 1.1 定义

二叉树是每个节点**最多有两个孩子**（左孩子、右孩子）的树结构。左右孩子有区别，交换后是不同的树。

### 1.2 节点的度

- **度为 0**：叶子节点（无孩子）
- **度为 1**：只有一个孩子
- **度为 2**：有两个孩子

### 1.3 核心性质（必背公式）

| 性质 | 公式 | 说明 |
|:---|:---|:---|
| 第 i 层最多节点数 | **2^(i-1)** | 根为第 1 层 |
| 深度为 k 最多节点数 | **2^k - 1** | 根深度为 1 |
| 叶子与度为2节点的关系 | **n0 = n2 + 1** | 任何二叉树都成立 |
| 总边数 | **n - 1** | n 个节点 n-1 条边 |

> **推导 n0 = n2 + 1：** 设总节点 n = n0 + n1 + n2。除根外每个节点都有唯一父指针指向它，故边数 = n - 1 = n1 + 2·n2。联立得 n0 = n2 + 1。

> **对应习题：** 第 1、2、3 题

## 二、完全二叉树

### 2.1 定义

深度为 k、有 n 个节点的二叉树，当且仅当其每个节点都与深度为 k 的满二叉树中编号 1~n 的节点**一一对应**时，称为完全二叉树。

通俗理解：**从上到下、从左到右**依次排满，最后一层可以不满，但必须靠左对齐。

```
        1                 1
       / \               / \
      2   3             2   3
     / \  /            / \  / \
    4  5 6            4  5 6  7
   ✅ 完全二叉树        ✅ 完全二叉树(也是满二叉树)
```

### 2.2 核心性质（按层序编号，根为 1）

| 性质 | 公式 |
|:---|:---|
| 深度 | **⌊log₂(n)⌋ + 1** |
| 节点 i 的左孩子 | **2i**（若 2i ≤ n） |
| 节点 i 的右孩子 | **2i + 1**（若 2i+1 ≤ n） |
| 节点 i 的父节点 | **⌊i/2⌋** |
| 叶子节点数 | **⌈n/2⌉** |
| 叶子出现位置 | 只在**最后一层**和**倒数第二层** |
| 深度 k 的节点数范围 | **[2^(k-1), 2^k - 1]** |
| 最后一个有孩子的节点编号 | **⌊n/2⌋** |

> **速记：** 编号大于 ⌊n/2⌋ 的全是叶子；编号 i 有左孩子 ⟺ 2i ≤ n。

> **对应习题：** 第 4、5、6、7、8、24 题

## 三、满二叉树

### 3.1 定义

深度为 k 且有 **2^k - 1** 个节点的二叉树。每一层都"排满"，所有非叶子节点都有两个孩子。

### 3.2 核心性质

| 性质 | 公式 |
|:---|:---|
| 总节点数 | **2^k - 1** |
| 叶子节点数 | **2^(k-1)**（全在最底层） |
| 第 i 层节点数 | **2^(i-1)** |
| 非叶子节点数 | **2^(k-1) - 1** |
| 叶子数 = 非叶子数 + 1 | 符合 n0 = n2 + 1 |

> **关系：** 满二叉树一定是完全二叉树；完全二叉树不一定是满二叉树。

> **对应习题：** 第 9、10、11、24 题

## 四、前中后序遍历

### 4.1 三种遍历定义

设根为 D，左子树为 L，右子树为 R：

| 遍历方式 | 访问顺序 | 助记 |
|:---|:---|:---|
| **前序**（先序） | **D → L → R** | 根左右 |
| **中序** | **L → D → R** | 左根右 |
| **后序** | **L → R → D** | 左右根 |

```
        A
       / \
      B   C
     / \   \
    D   E   F

前序：A B D E C F
中序：D B E A C F
后序：D E B F C A
```

> **关键结论：**
> - 前序第一个 = 根；后序最后一个 = 根
> - 中序中根的位置划分左、右子树
> - 前序看"根"，中序看"分界"

### 4.2 遍历还原二叉树

| 已知 | 能否唯一确定 | 方法 |
|:---|:---|:---|
| 前序 + 中序 | ✅ 能 | 前序首字符定根，中序划左右 |
| 中序 + 后序 | ✅ 能 | 后序末字符定根，中序划左右 |
| 前序 + 后序 | ❌ 不能 | 单分支节点无法区分左右孩子 |

### 4.3 还原通用算法（递归分治）

```
已知前序 pre 和中序 ino，还原树：
1. pre[0] 是根 root
2. 在 ino 中找到 root 的位置 idx
3. 左子树 = 还原(pre[1..idx], ino[0..idx-1])
4. 右子树 = 还原(pre[idx+1..], ino[idx+1..])
5. 返回 root

已知中序 ino 和后序 post 同理，只是根在 post 末尾。
```

### 4.4 易错点

1. **前序+后序不唯一**：当某非叶子节点只有一个孩子时，无法判断是左孩子还是右孩子。
2. **只有所有非叶子节点都有两个孩子时**，前序+后序才能唯一确定二叉树。
3. 还原时注意：前序/后序中"根之后紧跟的若干个"对应左子树，个数由中序确定。

> **对应习题：** 第 12、13、14、15、16、17 题

## 五、前中后缀表达式

### 5.1 三种表达式

| 类型 | 运算符位置 | 示例（(a+b)*c） |
|:---|:---|:---|
| **中缀** | 运算符在两操作数中间 | `a + b` |
| **前缀**（波兰式） | 运算符在操作数前 | `+ a b` |
| **后缀**（逆波兰式） | 运算符在操作数后 | `a b +` |

> 后缀表达式**不需要括号**，运算符优先级已隐含在顺序中，计算机求值最方便。

### 5.2 中缀转后缀（手工 / 调度场算法）

**步骤：**
1. 从左到右扫描中缀式
2. 遇到**操作数**：直接输出
3. 遇到 **`(`**：入栈
4. 遇到 **`)`**：弹栈并输出，直到遇到 `(`
5. 遇到**运算符**：弹栈并输出，直到栈顶优先级**小于**当前运算符；然后当前运算符入栈
6. 扫描完：栈中剩余运算符依次弹出输出

**优先级：** `* /` > `+ -` > `(`

**示例：** `(a+b)*c-d`
```
扫描 (  → 栈:[(]
扫描 a  → 输出:a
扫描 +  → 栈:[(, +]
扫描 b  → 输出:ab
扫描 )  → 弹+输出:ab+ ， 弹掉(
扫描 *  → 栈:[*]
扫描 c  → 输出:ab+c
扫描 -  → 弹*输出:ab+c* ， -入栈:[-]
扫描 d  → 输出:ab+c*d
结束    → 弹-输出:ab+c*d-
```

### 5.3 中缀转前缀

**方法一（推荐）：**
1. 中缀式**反转**
2. `(` 与 `)` 互换
3. 按转后缀的方式处理（注意：相同优先级时**不弹出**，即用 `>` 而非 `≥`）
4. 结果再**反转**

**方法二：** 从最低优先级运算符开始，递归地对左右两部分转换。

**示例：** `a+b*(c-d)-e/f`
```
最后一步是 - ，左边 a+b*(c-d)，右边 e/f
  右边 e/f → /ef
  左边 a+b*(c-d)，最后一步是 + ，左边 a，右边 b*(c-d)
    b*(c-d) → *b-cd ，其中 (c-d) → -cd
    → +a*b-cd
→ -+a*b-cd/ef
```

### 5.4 后缀表达式求值（栈）

**步骤：**
1. 从左到右扫描
2. 遇到**操作数**：入栈
3. 遇到**运算符 op**：弹出栈顶 b，再弹出 a，计算 `a op b`，结果入栈
4. 扫描完，栈中唯一元素即为结果

> **注意顺序：** 先弹出的是**右操作数 b**，后弹出的是**左操作数 a**，计算 `a op b`。减法和除法顺序不能反！

**示例：** `5 1 2 + 4 * + 3 -`
```
5     → 栈:[5]
1     → 栈:[5,1]
2     → 栈:[5,1,2]
+     → 弹2,1 → 1+2=3 → 栈:[5,3]
4     → 栈:[5,3,4]
*     → 弹4,3 → 3*4=12 → 栈:[5,12]
+     → 弹12,5 → 5+12=17 → 栈:[17]
3     → 栈:[17,3]
-     → 弹3,17 → 17-3=14 → 栈:[14]
结果 = 14
```

### 5.5 前缀表达式求值

**方法：从右到左扫描**，遇到操作数入栈，遇到运算符弹出两个操作数计算（先弹出的是左操作数）。

或递归：从左到右，遇到运算符就递归求值其两个操作数。

> **对应习题：** 第 18、19、20、21、22、23、25 题

## 六、知识结构总览

```
二叉树
├── 基础概念
│   ├── 度（0/1/2）
│   ├── n0 = n2 + 1
│   ├── 第i层 ≤ 2^(i-1)
│   └── 深度k ≤ 2^k - 1
├── 特殊形态
│   ├── 完全二叉树（编号关系、深度、叶子数）
│   └── 满二叉树（2^k-1、2^(k-1)叶子）
├── 遍历
│   ├── 前序 DLR / 中序 LDR / 后序 LRD
│   └── 还原：前+中 ✅、中+后 ✅、前+后 ❌
└── 表达式
    ├── 中缀 ⇄ 前缀 ⇄ 后缀
    ├── 中缀转后缀：调度场算法
    └── 后缀求值：栈（左op右）
```
