## 一、选择题答案与解析

---
### 计算机的产生与发展（第 1–2 题）

**1.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 冯·诺依曼提出的是"存储程序"体系结构，不是智能测试 |
| B ✅ | **图灵测试**：图灵于 1950 年提出，用于检验机器是否具有智能 |
| C | ❌ 摩尔定律是关于晶体管数量的经验规律 |
| D | ❌ 香农是信息论奠基人 |

> 考点：图灵测试的提出者与用途。真题常考"图灵测试"与"图灵奖"的区别（测试 vs 奖项）。

---

**2.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | 根据**局部性原理**，在 CPU 与主存之间引入**高速缓存（Cache）**，缓存最近访问的数据，提高执行效率 |
| B | ❌ 闪存（Flash）属于外部存储，速度慢 |
| C | ❌ 外存速度更慢 |
| D | ❌ 寄存器本来就属于 CPU，不是"引入"的 |

> 考点：Cache 的引入原因（局部性原理）。真题原题。注意：寄存器是 CPU 内部已有的，Cache 是"额外引入"的。

### 计算机系统组成（第 3–4 题）

**3.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ SSD 属于**外存储器**，断电后数据不丢失 |
| B | ❌ Cache 容量比内存**小**（越快越小） |
| C | ❌ 硬盘比内存**慢** |
| D ✅ | ROM（只读存储器）**断电不丢失**，一般只能读出、不能改写 |

> 考点：RAM vs ROM vs 外存的易失性（提高版：加入 SSD 判断）。

---

**4.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | 显示器、打印机、音响都是**输出设备** |
| B | ❌ 键盘、鼠标、扫描仪都是**输入**设备 |
| C | ❌ 键盘、摄像头是输入设备 |
| D | ❌ 麦克风是输入设备 |

> 考点：输入/输出设备分类（真题原题变式）。陷阱：触摸屏既是输入又是输出（本题 D 因此错误）。

### 信息的表示与存储（第 5–10 题）⭐ 重点

**5.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 57 是字符 `'9'` 的 ASCII 码，不是表达式的值 |
| B ✅ | `'9' - '0'` = 57 - 48 = **9**（字符数字相减得到数值） |
| C | ❌ 48 是 `'0'` 的 ASCII 码 |
| D | ❌ 8 是 `'8' - '0'` 的值 |

> 考点：字符数字与数值的转换（`'9'-'0'` = 9）。真题常考：数字字符的 ASCII 码连续，`'x' - '0'` 得到数字 x。

---

**6.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 0.101 是二进制写法本身，不是十进制值 |
| B | ❌ 0.5 只有第一位（2⁻¹） |
| C | ❌ 0.75 = 2⁻¹ + 2⁻² |
| D ✅ | `(0.101)₂` = 1×2⁻¹ + 0×2⁻² + 1×2⁻³ = 0.5 + 0.125 = **0.625** |

> 考点：二进制小数转十进制（按权展开，负次幂）。比前两套的整数进制转换加深一步。

---

**7.** 答案 **C**

| 选项 | 分析 |
|------|------|
| A | ❌ -5 不是 `~5` 的结果 |
| B | ❌ 250 是 8 位**无符号**视角的值（11111010） |
| C ✅ | 5 = 00000101，按位取反得 11111010（补码）= **-6**（因为 -6 的补码正是 11111010） |
| D | ❌ 6 是 5 的相反数位运算？不对：~5 ≠ 6 |

> 考点：按位取反 `~`（补码视角，`~x = -x - 1`）。陷阱：250 是"看成无符号数"的错解。

---

**8.** 答案 **A**

| 选项 | 分析 |
|------|------|
| A ✅ | `8 & 12` = (1000 & 1100) = 1000 = 8；`4 ^ 7` = (0100 ^ 0111) = 0011 = 3；`8 \| 3` = (1000 \| 0011) = 1011 = **11** |
| B | ❌ 8 只算了第一步 `8 & 12` |
| C | ❌ 15 是 `8 \| 7` 之类错误 |
| D | ❌ 3 只算了 `4 ^ 7` |

> 考点：**复合位运算**（先算括号内，再算括号外）。比第 1、2 套的单步位运算加深：两步运算 + 三种运算符混合。

---

**9.** 答案 **B**

| 选项 | 分析 |
|------|------|
| A | ❌ 4.6 MB 是 1280×720×24 位的视频题数值，混淆项 |
| B ✅ | 1600×1200×24 bit ÷ 8 = 5,760,000 B；÷1024² ≈ **5.49 MB ≈ 5.5 MB** |
| C | ❌ 2.75 MB 是 16 位色的结果 |
| D | ❌ 8.25 MB 是按 36 位算的 |

> 考点：图片大小 = 宽 × 高 × 色彩位数。24 位色 = 3 字节/像素，1600×1200×3 = 5,760,000 B ≈ 5.5 MB。

---

**10.** 答案 **D**

| 选项 | 分析 |
|------|------|
| A | ❌ 0.48 GB 少算了 |
| B | ❌ 3.86 GB 是 60 秒的数值（时长算成 20 秒） |
| C | ❌ 0.97 GB 是 24 位色的数值 |
| D ✅ | 1920×1080×32 bit = 66,355,200 bit/帧；÷8 = 8,294,400 B/帧；×25 帧 ×10 秒 = 2,073,600,000 B；÷1024³ ≈ **1.93 GB** |

> 考点：视频大小 = 宽 × 高 × 色位 × 帧率 × 时长。注意本题帧率 25、时长 10 秒，与前两套数值不同，需仔细算。

## 判断题答案与解析

**21.** 答案 **✅**（T）

图灵测试由**阿兰·图灵**于 1950 年提出（论文《计算机器与智能》），是检验机器智能的经典思想实验。

> 考点：图灵测试提出者与用途。

---

**22.** 答案 **✅**（T）

GB2312 / GBK 编码中，一个汉字占 **2 字节**（ASCII 字符占 1 字节）。

> 考点：汉字编码长度。比第 2 套"1 字节 = 8 位"更深一层（字符集编码）。

---

**23.** 答案 **❌**（F）

存储层次速度：**寄存器 > Cache > 内存（RAM）> 硬盘**。Cache 比内存快，所以说法相反。

> 考点：存储层次速度排序（换角度考：把"谁快"变成判断题）。

---

**24.** 答案 **❌**（F）

计算机中 **1KB = 1024 字节**、1MB = 1024KB（按 1024 进制）；1000 进制是厂商标称。

> 考点：1024 vs 1000 进制（第 2 套考过 1MB，本套换 1KB 再考一次强化）。

---

**25.** 答案 **❌**（F）

`1101₂` = 8+4+1 = **13**，与十进制 13 **相等**，不是大于。

> 考点：二进制转十进制比较（"大于/小于/等于"判断）。

---

**26.** 答案 **✅**（T）

8 位补码范围 -128 ~ +127。127+1 = 128 超出范围，**溢出**，结果按补码回绕为 **-128**（10000000）。

> 考点：补码溢出（提高考点）。C++ 中 int 溢出行为同理（未定义但常见回绕）。

---

**27.** 答案 **❌**（F）

只有**编译型**语言需要先编译；**解释型**语言（Python、JavaScript）逐句解释执行，无需先编译成机器码。

> 考点：编译型 vs 解释型（与第 11 题呼应）。

---

**28.** 答案 **✅**（T）

完整域名 www.noi.cn 中：**www 是主机名**，**noi.cn 是域名**（noi 是二级域名，cn 是顶级域名）。

> 考点：域名结构（主机名.域名）。比第 1、2 套的"cn 是顶级域名"更完整。

---

**29.** 答案 **✅**（T）

操作系统是**系统软件的核心**，负责管理硬件资源、软件资源，提供用户接口。

> 考点：操作系统的地位与作用。

---

**30.** 答案 **✅**（T）

位运算中异或 `^` 满足**交换律**（a^b = b^a）和**结合律**（(a^b)^c = a^(b^c)），且 a^a = 0、a^0 = a——这是"异或交换"技巧的基础。

> 考点：异或运算性质（提高考点，为位运算技巧题打基础）。
