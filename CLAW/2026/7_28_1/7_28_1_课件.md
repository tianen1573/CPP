## Part 1：引子——从一道天真的题开始

### 问题

> 有一个数列 `a`，共 `n` 个数。现在有 `m` 次询问，每次问你 `a[l]` 到 `a[r]` 的和，怎么做？

### 天真的做法

```cpp
for (int i = l; i <= r; i++) sum += a[i];
```

每次询问都从 l 循环到 r，把所有数加一遍。

**时间：** O(n × m)

- n = 10⁵，m = 10⁵ → 最坏 10¹⁰ 次运算 → **完蛋。**

### 能不能快一点？

仔细想想——每次都要把 l 到 r 的每个数当场加一遍，但中间大量数字被重复加了。

**核心思想：能不能提前把所有区间和都算好存下来？**

比如：
- 存好 `a[1] ~ a[1]` 的和
- 存好 `a[1] ~ a[2]` 的和
- 存好 `a[1] ~ a[3]` 的和
- ……
- 存好 `a[1] ~ a[n]` 的和

那要算 `a[l] ~ a[r]` 的和时，是不是有办法直接"减"出来？

👇 这就是前缀和的思想。

## Part 2：前缀和 —— 预先把"和"算好

### 定义

定义一个新数组 `pre`，其中：

```
pre[0] = 0
pre[i] = a[1] + a[2] + ... + a[i]   (i = 1..n)
```

用递推写就是：

```
pre[i] = pre[i-1] + a[i]
```

### 构造过程举例

```
a:  [_, 3, 1, 4, 1, 5, 9, 2, 6]     （下标从 1 开始）
        ↑  ↑  ↑  ↑  ↑  ↑  ↑  ↑
        1  2  3  4  5  6  7  8
```

| i | a[i] | pre[i] = pre[i-1] + a[i] |
|---|---|---|
| 0 | — | 0 |
| 1 | 3 | 0 + 3 = 3 |
| 2 | 1 | 3 + 1 = 4 |
| 3 | 4 | 4 + 4 = 8 |
| 4 | 1 | 8 + 1 = 9 |
| 5 | 5 | 9 + 5 = 14 |
| 6 | 9 | 14 + 9 = 23 |
| 7 | 2 | 23 + 2 = 25 |
| 8 | 6 | 25 + 6 = 31 |

```
pre:  [0, 3, 4, 8, 9, 14, 23, 25, 31]
```

### 核心公式：区间和查询

```
sum[l..r] = pre[r] - pre[l-1]
```

**图解验证：** 想求 `a[3] + a[4] + a[5]`（即下标 3 到 5 的和）

```
pre[5] = a[1]+a[2]+a[3]+a[4]+a[5] = 14
pre[2] = a[1]+a[2]                 =  4
—————
相减       a[3]+a[4]+a[5]          = 10 ← 正好
```

**验证数值：** a[3]=4 + a[4]=1 + a[5]=5 = 10 ✓

> 为什么 pre[0] 要设为 0？
> 为了公式统一。如果 l = 1，`pre[1] - pre[0]` = pre[1] - 0 = a[1]，公式依然成立。没有 pre[0] = 0，l=1 就要特判。

### 代码模板

```cpp
#include <iostream>
using namespace std;

const int N = 100010;
int a[N], pre[N];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i-1] + a[i];          // 边读边构造
    }
    while (m--) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l-1] << endl; // O(1) 回答
    }
    return 0;
}
```

**时间复杂度：** O(n + m)，比天真的 O(n×m) 快了一个数量级。

## Part 4：差分 —— 反过来想问题

### 新问题

> 有一个数组 `a`，初始全部为 0。现在要做 `m` 次操作，每次操作把 `a[l]` 到 `a[r]` 的所有数 **加上同一个值 x**。所有操作结束后，输出最终的数组。

### 天真的做法

```cpp
for (int i = l; i <= r; i++) a[i] += x;
```

每次 O(r-l+1)，m 次最坏 O(n×m)，又完蛋。

### 关键观察

如果有一对 **逆运算**，其中一个"麻烦操作"在另一个的世界里就变成了"简单操作"——

**前缀和的逆运算是什么？**

让我们理一理。

已知 pre 是 a 的前缀和：
```
pre[i] = a[1] + a[2] + ... + a[i]
```

那反过来说：
```
a[1] = pre[1]
a[2] = pre[2] - pre[1]
a[3] = pre[3] - pre[2]
...
a[i] = pre[i] - pre[i-1]
```

这个逆运算就叫 **差分**。

### 差分的定义

定义差分数组 `diff`：

```
diff[1] = a[1]
diff[i] = a[i] - a[i-1]    (i >= 2)
```

**验证：对 diff 求前缀和，能得到原数组 a 吗？**

```
preDiff[1] = diff[1] = a[1]
preDiff[2] = diff[1] + diff[2] = a[1] + (a[2]-a[1]) = a[2]
preDiff[3] = diff[1] + diff[2] + diff[3] = a[1] + (a[2]-a[1]) + (a[3]-a[2]) = a[3]
```

✔ **把 diff 求一遍前缀和，就还原回了原数组 a。**

---

### 核心魔法：区间加如何变成 O(1)

回到问题：想给 a[l] ~ a[r] 每个数加 x。

**操作：**
```
diff[l] += x;
diff[r+1] -= x;
```

**为什么？**

思想方向：计算过程是 **diff → 求前缀和 → 得到 a**。

- 在 diff[l] 处加 x → 前缀和一路传到后面，所有 >= l 的 a[i] 都多了 x
- 但我不想影响 r 之后的数，所以在 diff[r+1] 处减 x → 到 r+1 开始又抵消了

**效果：**

```
位置:     l     l+1   ...   r     r+1    r+2
———————————————
diff:    +x     0     ...   0     -x     0
前缀和:  +x    +x     ...  +x     0      0
                                   ↑
                             刚好到 r 为止 +x
```

**神奇吗？其实是数学在背后撑腰。**

### 差分构造举例

> a = [0, 0, 0, 0, 0, 0]，三次操作：
> 1. [2, 4] 加 3
> 2. [1, 3] 加 2
> 3. [3, 5] 加 5

**操作 diff 数组：**

初始 diff = [0, 0, 0, 0, 0, 0, 0]（要开到 n+2，因为可能操作到 r+1）

```
操作1: [2,4] +3  → diff[2]+=3, diff[5]-=3
操作2: [1,3] +2  → diff[1]+=2, diff[4]-=2
操作3: [3,5] +5  → diff[3]+=5, diff[6]-=5
```

| 位置 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 初始 diff | 0 | 0 | 0 | 0 | 0 | 0 |
| 操作1后 | 0 | +3 | 0 | 0 | -3 | 0 |
| 操作2后 | +2 | +3 | 0 | -2 | -3 | 0 |
| 操作3后 | +2 | +3 | +5 | -2 | -3 | -5 |

**求前缀和还原 a：**

```
a[1] = 0 + 2 = 2
a[2] = 2 + 3 = 5
a[3] = 5 + 5 = 10
a[4] = 10 + (-2) = 8
a[5] = 8 + (-3) = 5
a[6] = 5 + (-5) = 0
```

结果：a = [2, 5, 10, 8, 5, 0]

**手动验证：**
- 原数组全 0
- 操作1 [2,4]+3 → [0,3,3,3,0,0]
- 操作2 [1,3]+2 → [2,5,5,3,0,0]
- 操作3 [3,5]+5 → [2,5,10,8,5,0] ✓

---

### 代码模板

```cpp
#include <iostream>
using namespace std;

const int N = 100010;
int diff[N];    // 直接用 diff 数组（初始全 0）

int main() {
    int n, m;
    cin >> n >> m;
    // 如果初始数组不是全 0，先通过 diff 构造出来
    // for (int i = 1; i <= n; i++) {
    //     int x; cin >> x;
    //     diff[i] += x;          // 在 i 处加 x，然后在 i+1 处减 x → 等价于放一个数
    //     diff[i+1] -= x;
    // }
    while (m--) {
        int l, r, x;
        cin >> l >> r >> x;
        diff[l] += x;
        diff[r+1] -= x;
    }
    // 最后求前缀和得到最终数组
    for (int i = 1; i <= n; i++) {
        diff[i] += diff[i-1];   // 原地前缀和
        cout << diff[i] << " \n"[i==n];
    }
    return 0;
}
```

**时间复杂度：** O(n + m)，每次区间加 O(1)。

## Part 6：前缀和 vs 差分 —— 双胞胎对比

| 特性 | 前缀和 (Prefix Sum) | 差分 (Difference) |
|---|---|---|
| **是什么** | 把和提前算好存着 | 记录相邻元素的差值 |
| **公式** | pre[i] = pre[i-1] + a[i] | diff[i] = a[i] - a[i-1] |
| **关系** | — | 对 diff 求前缀和 = 原数组 a |
| **核心操作** | O(1) 求 `a[l] ~ a[r]` 的和 | O(1) 给 `a[l] ~ a[r]` 加一个数 |
| **操作公式** | sum = pre[r] - pre[l-1] | diff[l] += x, diff[r+1] -= x |
| **适合场景** | **多次区间查和** | **多次区间加值** |
| **为什么快** | 预计算，空间换时间 | 把区间操作转化为端点操作 |

---

### 一句话理解

- **前缀和：** 先把历史算好存着，每次查的时候直接减一下（预处理 → 快速查询）
- **差分：** 先把要改的地方标记在端点，最后一起算（标记 → 统一还原）

**它俩是逆运算，知道一个就能推出另一个。**

## Part 7：两道实战例题

### 例 1 —— 最高海拔（前缀和应用）

> 一位骑手从海拔 0 开始骑行。已知 n 段路程中每段的海拔变化量 gain[i]（可为正或负），求骑行过程中达到的**最高海拔**。
>
> 输入：gain = [-5, 1, 5, 0, -7]
> 输出：1

**思路：** 海拔数组是 gain 的前缀和。

```
海拔: 0 → (-5) → (-4) → 1 → 1 → (-6)
                   ↑
                最高 1
```

直接求前缀和，同时记录最大值。

```cpp
int largestAltitude(vector<int>& gain) {
    int cur = 0, ans = 0;
    for (int x : gain) {
        cur += x;          // 递推前缀和（当前位置的海拔）
        ans = max(ans, cur);
    }
    return ans;
}
```

### 例 2 —— 航班预订统计（差分应用）

> 有 n 个航班，编号 1~n。给你一个 bookings 数组，每个 bookings[i] = [l, r, x] 表示预订了从 l 到 r 的每个航班 x 个座位。
> 返回长度为 n 的数组 answer，answer[i] 表示航班 i 的总预订数。

这就是典型的 **多次区间加 → 最后输出** 场景，差分完全适用。

```cpp
vector<int> corpFlightBookings(vector<vector<int>>& bookings, int n) {
    vector<int> diff(n + 2, 0);  // 多开一些，避免越界
    for (auto& b : bookings) {
        int l = b[0], r = b[1], x = b[2];
        diff[l] += x;
        diff[r+1] -= x;
    }
    vector<int> ans(n);
    int cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += diff[i];      // 前缀和还原
        ans[i-1] = cur;
    }
    return ans;
}
```

## Part 8：本课小结 & 易错点

### ✅ 必须记住的

| 公式 | 用途 |
|---|---|
| `pre[i] = pre[i-1] + a[i]` | 构造前缀和 |
| `sum[l..r] = pre[r] - pre[l-1]` | 查询区间和 |
| `diff[i] = a[i] - a[i-1]` | 构造差分 |
| `diff[l] += x, diff[r+1] -= x` | 区间加操作 |
| 对 diff 求前缀和 = 原数组 | 差分还原 |

### 🔴 常见易错

| 错误 | 正确 | 原因 |
|---|---|---|
| 数组开到 n 刚好 | 开到 n+2 | diff[r+1] 会访问 n+1 |
| 忘记 long long | 结果或 pre 用 long long | n=10⁵、值=10⁹ 时 pre[n] 可能爆 int |
| pre[i] 写成 `pre[i] += a[i]` | `pre[i] = pre[i-1] + a[i]` | 不是累加，是递推 |
| 差分时 `diff[r] -= x` | `diff[r+1] -= x` | 是 r 的下一个位置才开始抵消 |
| 多组测试不重置 pre[0] | pre[0] = 0 每次清空 | 上一组的数据会干扰下一组 |

### 💡 选讲（时间够就提一下）

- **二维前缀和 / 差分**是同一个思想的二维扩展，后续再讲
- 前缀和还可以做 **子数组和等于 k** 的问题（配合哈希表）
- 差分还能做 **扫描线、区间覆盖** 等问题
