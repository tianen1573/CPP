## 一、选择题答案与解析

---
### 计算机的产生与发展（第 1–7 题）

**1.** 答案 **C** — 宾夕法尼亚大学

**解析：**
- ENIAC 于 1946 年在 **美国宾夕法尼亚大学** 研制成功
- 是世界上第一台电子数字计算机

> 🧠 ENIAC = 宾夕法尼亚大学，常考点。

---

**2.** 答案 **A** — 编译器

**解析：**
- 冯·诺依曼体系结构五大部件：**运算器、控制器、存储器、输入设备、输出设备**
- 编译器属于软件，不是硬件部件

> 🧠 五大部件口诀：运算控制器，存储输输出。

---

**3.** 答案 **D** — 超大规模集成电路

**解析：**
- 第四代计算机（1970–至今）：**大规模/超大规模集成电路**
- 第一代：电子管 → 第二代：晶体管 → 第三代：集成电路 → 第四代：超大规模集成电路

> 🧠 四代元件：电→晶→集→超集。

---

**4.** 答案 **A** — 18–24 个月

**解析：**
- **摩尔定律**（戈登·摩尔，1965）：集成电路上晶体管数量约每 **18–24 个月** 翻一番
- 性能同步提升，成本降低

> 🧠 摩尔定律是经验观察，不是物理定律，但过去几十年基本成立。

---

**5.** 答案 **D** — 菲尔兹奖

**解析：**
- 菲尔兹奖 → 数学界最高荣誉（四年一次）
- 图灵奖 → 计算机科学（"计算机界的诺贝尔奖"）
- 普利策奖 → 新闻、文学

> 🧠 常见混淆：图灵奖（计算机）vs 菲尔兹奖（数学）。

---

**6.** 答案 **C** — AlphaGo

**解析：**
- 中国巨型计算机代表：**银河、天河、神威·太湖之光**
- AlphaGo 是 Google DeepMind 开发的围棋 AI 程序，不是计算机

> 🧠 巨型机常考："银河"、"天河"、"神威·太湖之光"。

---

**7.** 答案 **A** — 能完全自主创新

**解析：**
- 计算机的特点：运算速度快、计算精度高、存储容量大、具有逻辑判断能力、自动化程度高
- 计算机 **不能完全自主创新**，它按照人类编写的程序执行

> 🧠 计算机只能按程序执行，不具备人类意义上的创造力。

---
### 计算机系统组成（第 8–12 题）

**8.** 答案 **D** — 运算器（ALU）

**解析：**
- **运算器（ALU）** = 算术逻辑单元，负责算术运算（加减乘除）和逻辑运算（与或非）
- A ✗ — 控制器负责指令译码和流程控制
- B ✗ — 寄存器用于暂存数据
- C ✗ — Cache 是高速缓存

> 🧠 ALU 做运算，CU 做控制。

---

**9.** 答案 **D** — 存储容量比内存大

**解析：**
- Cache 是 **高速缓存**，位于 CPU 内部或附近，速度比内存快
- 但 Cache 的 **容量远小于内存**（通常几 MB，内存是 GB 级）
- Cache 断电丢失（属于易失性存储）

> 🧠 Cache 特点是快但小，不是大但慢。

---

**10.** 答案 **B** — CPU 是一个博士生，GPU 是一万个小学生

**解析：**
- 通俗理解：CPU（博士生）能解决各种复杂问题；GPU（一万个小学生）只会简单计算但人多力量大
- 深度学习任务就是大量简单矩阵乘法，GPU 特别适合

> 🧠 CPU 灵活但核少，GPU 核多但功能单一，各司其职。

---

**11.** 答案 **B** — 地址总线（AB）

**解析：**
- 三种总线：
  - **地址总线（AB）**：传输内存地址信息
  - 数据总线（DB）：传输数据
  - 控制总线（CB）：传输控制信号
- 地址总线位数决定 CPU 寻址能力（如 32 位最大寻址 4GB）

> 🧠 AB 寻址，DB 传数，CB 发号施令。

---

**12.** 答案 **A** — 硬盘

**解析：**
- 存储容量从大到小：**硬盘 > 内存 > Cache > 寄存器**
- 速度则相反：寄存器 > Cache > 内存 > 硬盘

> 🧠 容量和速度成反比：越快越小，越慢越大。

---
### 信息的表示与存储（第 13–18 题）

**13.** 答案 **A** — 65

**解析：**
- 二进制转八进制：**三位分组法**（从右向左）
- `110101` → 110 101 → 6 5 → **65₈**

> 🧠 二→八：三位一组，从右向左。二→十六：四位一组。

---

**14.** 答案 **C** — 25

**解析：**
- 八进制转十进制：**按权展开**
- (31)₈ = 3×8¹ + 1×8⁰ = 24 + 1 = **25**

> 🧠 八进制每一位的权是 8 的幂。

---

**15.** 答案 **B** — 补码的补码等于原码

**解析：**
- 补码性质：**补码的补码 = 原码**
- A ✗ — 正数的补码等于原码本身，不是取反
- C ✗ — 负数补码 = 反码 + 1，不是原码 + 1
- D ✗ — 0 在补码中只有唯一表示（全 0）

> 🧠 A 正数三码合一；B ✓ 补码两次还原；C 缺取反步骤；D 0 唯一。

---

**16.** 答案 **B** — 1.7 GB

**解析：**
- 视频大小 = 宽 × 高 × 色彩位数 × 帧率 × 时长
- = 1920 × 1080 × 24 × 30 × 10
- = 14,929,920,000 bit
- ÷8 = 1,866,240,000 Byte
- ÷1024÷1024÷1024 ≈ **1.74 GB** ≈ 1.7 GB

> 🧠 视频计算比图片多乘一个帧率×时长。单位换算小心。

---

**17.** 答案 **C** — -1

**解析：**
- `~` 是按位取反运算符
- 在补码表示中，全 0 取反 = 全 1
- 8 位：`~00000000` = `11111111`，即 -1 的补码

> 🧠 ~0 = -1。这是补码表示的特性，CSP-J 常考。

---

**18.** 答案 **C** — UTF-8

**解析：**
- **UTF-8** 是 Unicode 的**可变长编码**，英文字符用 1 字节，汉字用 3 字节
- ASCII：固定 7/8 位，定长
- Unicode（UCS-2/UTF-16）：固定或双字节，统一编码
- GB2312：汉字编码标准，固定 2 字节

> 🧠 可变长编码好处：节省空间，兼容 ASCII。

### 计算机语言（第 19–20 题）

**19.** 答案 **B** — Windows

**解析：**
- **操作系统（OS）**：Windows、Linux、macOS、Android、iOS
- MySQL → 数据库管理系统
- Chrome → 浏览器（应用软件）
- Word → 办公软件（应用软件）

> 🧠 操作系统是系统软件的核心，管理硬件和软件资源。

---

**20.** 答案 **A** — 递归

**解析：**
- 面向对象三大特征：**封装、继承、多态**
- 递归是一种编程技巧（函数调用自身），不是面向对象特征

> 🧠 封一继二多态三，递归是技巧不是特征。

---
### 计算机网络基础（第 21–24 题）

**21.** 答案 **B** — MAN（城域网）

**解析：**
- LAN（局域网）：一栋楼/一个园区
- **MAN（城域网）**：一座城市
- WAN（广域网）：跨国家/全球

> 🧠 按范围：LAN < MAN < WAN。

---

**22.** 答案 **A** — C 类

**解析：**
- IPv4 分类：
  - A 类：1.0.0.0–127.255.255.255（首位 0）
  - B 类：128.0.0.0–191.255.255.255（前两位 10）
  - **C 类：192.0.0.0–223.255.255.255（前三位 110）**
- 192.168.x.x 属于 C 类中的私有地址段

> 🧠 192 开头 → C 类；128–191 → B 类；1–126 → A 类。

---

**23.** 答案 **D** — FTP

**解析：**
- **FTP**（File Transfer Protocol）：文件传输协议
- HTTP → 超文本传输协议（网页）
- SMTP → 邮件发送协议
- DNS → 域名解析服务

> 🧠 FTP 传文件，HTTP 传网页，SMTP 发邮件，DNS 解析域名。

---

**24.** 答案 **C** — 8080

**解析：**
- URL 格式：`协议://主机:端口/路径`
- `https://www.noi.cn:8080/path` 中端口号明确写为 **8080**
- HTTPS 默认端口是 443，但这里指定了 8080

> 🧠 URL 中 `:` 后面的数字就是端口号。默认 HTTP=80，HTTPS=443。

---
### 信息安全（第 25 题）

**25.** 答案 **B** — 防火墙可以防止所有网络攻击

**解析：**
- 防火墙是 **网络边界防护设备**，可以是硬件或软件
- 但防火墙 **不能防止所有攻击**（如内部攻击、病毒邮件、社会工程攻击等）
- 防火墙只是网络安全纵深防御体系中的一环

> 🧠 没有绝对安全的设备。防火墙不是万能的。
