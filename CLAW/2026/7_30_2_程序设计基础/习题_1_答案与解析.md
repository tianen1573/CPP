## 一、选择题

**1. 答案：B**

| 选项 | 分析 |
|------|------|
| A ❌ | 指数增长 O(2ⁿ) 远快于多项式 O(n¹⁰) |
| B ✅ | 忽略常数和低阶项，O(3n+5) = O(n) |
| C ❌ | O(n² + n log n) = O(n²)，保留最高阶 |
| D ❌ | 复杂度描述的就是随数据规模的变化趋势 |

> 考点：时间复杂度计算规则——忽略常数、取最高阶。

---

**2. 答案：C**

算法五大特征：有穷性、确定性、可行性、输入、输出。"高并发"是计算机系统概念，不是算法特征。

> 考点：算法五大特征记忆。

---

**3. 答案：C**

| 选项 | 分析 |
|------|------|
| A ❌ | `int *p;` 未初始化是野指针，直接 `*p = 10;` 会崩溃 |
| B ❌ | `p+1` 跳过整个 `int`（4 字节），不是 1 字节 |
| C ✅ | `&x` 取变量 x 的地址，正确 |
| D ❌ | 数组名 `arr` 等价于 `&arr[0]` |

> 考点：指针的基本操作——取地址 &、解引用 *、指针偏移。

---

**4. 答案：D**

| 选项 | 分析 |
|------|------|
| A ✅ | `private` 成员只能在类内部访问，正确 |
| B ✅ | 类的成员函数可以访问私有成员，这是封装的基本设计 |
| C ✅ | 类定义末尾必须有分号，语法要求 |
| D ❌ | `public` 成员函数**可以**操作私有成员变量，这才是封装的正确用法 |

> 考点：类的访问权限和成员函数的作用。

---

**5. 答案：C**

| 选项 | 平均时间复杂度 |
|------|:------------:|
| A ❌ 冒泡排序 | O(n²) |
| B ❌ 选择排序 | O(n²) |
| C ✅ 快速排序 | O(n log n) |
| D ❌ 插入排序 | O(n²) |

> 考点：平均 O(n log n) 的三种排序——快排、归并、堆排（"快归堆"）。

---

**6. 答案：D**

| 选项 | 稳定性 |
|------|:-----:|
| A ❌ 选择排序 | ❌ 不稳定 |
| B ❌ 堆排序 | ❌ 不稳定 |
| C ❌ 快速排序 | ❌ 不稳定 |
| D ✅ 归并排序 | ✅ 稳定 |

> 考点：稳定排序：冒泡、插入、归并、计数、基数。选快堆不稳定。

**7. 答案：C**

```cpp
char s[] = "CSP-J";   // 实际存储：'C','S','P','-','J','\0'
cout << strlen(s);    // 5（不含 '\0'）
cout << sizeof(s);    // 6（含 '\0'，数组大小）
```

> 考点：`strlen` 和 `sizeof` 对 `'\0'` 的处理差异——strlen 数到 '\0' 为止，sizeof 算整个数组大小。

---

**8. 答案：A**

从 `head = 1` 开始遍历：

| 当前下标 | val | next |
|:-------:|:---:|:----:|
| 1 | **7** → 输出 | 3 |
| 3 | **9** → 输出 | 4 |
| 4 | **11** → 输出 | 2 |
| 2 | **15** → 输出 | -1 结束 |

→ 输出：`7, 9, 11, 15`

> 考点：数组模拟链表的遍历——跟着 `next` 指针走，直到 -1。

**9. 答案：C**

| 选项 | 分析 |
|------|------|
| A ❌ | 链表每个节点额外存指针，不一定节省内存 |
| B ❌ | 链表不支持 O(1) 随机访问 |
| C ✅ | **已知位置时**链表插入删除只需改指针，O(1)；数组需移动元素，O(n) |
| D ❌ | 链表涉及指针操作，代码更复杂 |

> 考点：链表的核心优势——插入删除高效。

**10. 答案：C**
A: 1入→1出→2入→2出→3入→3出→4入→4出→5入→5出 ✅
B: 1入→2入→3入→4入→5入→5出→4出→3出→2出→1出 ✅
C: 1入→2入→3入→4入→4出→5入→5出→**此时栈顶是3，不可能出1** ❌
D: 1入→2入→3入→3出→2出→1出→4入→4出→5入→5出 ✅

> 考点：栈的出栈合法性——不能跳过栈顶元素。

---

**11. 答案：C**

出栈顺序（= 出队顺序）：`b, c, f, e, d, a`

模拟过程，找栈的最大深度：

| 操作 | 栈内容 | 深度 | 出栈 |
|:----:|:------:|:----:|:----:|
| push a | [a] | 1 | |
| push b | [a,b] | **2** | |
| pop b | [a] | 1 | b |
| push c | [a,c] | 2 | |
| pop c | [a] | 1 | c |
| push d | [a,d] | 2 | |
| push e | [a,d,e] | **3** | |
| push f | [a,d,e,f] | **4** | |
| pop f | [a,d,e] | 3 | f |
| pop e | [a,d] | 2 | e |
| pop d | [a] | 1 | d |
| pop a | [] | 0 | a |

最大同时栈内元素数 = **4** → 容量至少为 4。

> 考点：栈容量分析——模拟入栈出栈过程，找最大深度。

## 二、判断题

**13. 答案：❌（错误）**

单向链表中，只知道节点 p 无法找到其前驱，所以删除 p 需要前驱节点来改写 `pre->next = p->next`。双向链表不需要（p->prev 可直接拿前驱）。

> 考点：单向链表删除的特性。

---

**14. 答案：❌（错误）**

循环队列中 `head == tail` 既可能表示空，也可能表示满。通常用「保留一个空位」或「额外 size 变量」来区分。

> 考点：循环队列空/满的判断陷阱。

---

**15. 答案：✅（正确）**

函数递归调用时，系统使用调用栈（call stack）保存每次递归的返回地址和局部变量。

> 考点：函数调用栈的概念。

---

**16. 答案：❌（错误）**

`strlen("hello")` 返回 **5**，因为 `strlen` 数到 `'\0'` 就停止，不包含 `'\0'` 自身。

> 考点：`strlen` vs `sizeof`——strlen 不含 `\0`。

## 三、完善程序

**17. 答案：B**

括号匹配遍历完所有字符后，如果所有括号都成对匹配，栈应回到初始空状态（`top == -1`）。

- A ❌ `top == 0` —— 还剩 1 个左括号没匹配
- B ✅ `top == -1` —— 栈空，全部匹配
- C ❌ `top >= 0` —— 还有未匹配的左括号
- D ❌ `top < 0` —— top 最小为 -1，不可能小于 -1

> 考点：括号匹配的结束条件——栈为空才说明全部匹配。
