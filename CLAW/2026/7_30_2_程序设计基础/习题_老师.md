## 三、完善程序（共 1 题，12 分）

**17.** 以下代码用数组模拟栈实现括号匹配。在横线处填入正确的选项。

```cpp
#include <iostream>
#include <cstring>
using namespace std;
char stk[100];
int top = -1;

bool check(char s[]) {
    int len = strlen(s);
    for (int i = 0; i < len; i++) {
        if (s[i] == '(' || s[i] == '[' || s[i] == '{') {
            stk[++top] = s[i];
        } else {
            if (top == -1) return false;
            char t = stk[top--];
            if (s[i] == ')' && t != '(') return false;
            if (s[i] == ']' && t != '[') return false;
            if (s[i] == '}' && t != '{') return false;
        }
    }
    return ① ;
}
```

① 处应填？
A. `top == 0`
B. `top == -1`
C. `top >= 0`
D. `top < 0`

> 答案：＿＿＿＿
