## 一、进制转换

### 1.1 常见进制与符号

| 进制 | 英文名 | 数字符号 | 后缀/前缀 |
|------|--------|----------|-----------|
| 二进制 | Binary | 0,1 | `B` / `0b` |
| 八进制 | Octal | 0–7 | `O` / `0` |
| 十进制 | Decimal | 0–9 | `D` / 无 |
| 十六进制 | Hex | 0–9, A–F(10–15) | `H` / `0x` |

> 字母大小写均可，A=10, B=11, C=12, D=13, E=14, F=15。

### 1.2 其它进制 → 十进制（按权展开）

公式：`(各位数字 × 基数的位权) 之和`，位权从右往左为 `基数⁰, 基数¹, ...`

```
(1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8+0+2+1 = 11
(65)₈   = 6×8¹ + 5×8⁰ = 48+5 = 53
(1A)₁₆  = 1×16¹ + 10×16⁰ = 16+10 = 26
```

### 1.3 十进制 → 其它进制

**整数部分：除基取余，逆序排列**（除到商为 0，余数从下往上读）

把 13 转二进制：

```
13 ÷ 2 = 6 余 1   ↑
 6 ÷ 2 = 3 余 0   │
 3 ÷ 2 = 1 余 1   │
 1 ÷ 2 = 0 余 1   ↓  (读序：从下往上)
```

→ `(1101)₂`

**小数部分：乘基取整，顺序排列**（CSP-J 初赛基本不考小数，了解即可）

把0.375转二进制

~~~
0.375 * 2 = 0.75
0.750 * 2 = 1.50
0.500 * 2 = 1.0
结果：0.011
正着取走整数部分，直到小数部分为0
~~~

→ `(0.011)₂`

### 1.4 二进制 ↔ 八进制 ↔ 十六进制（成组互换）

- **二 → 八**：从右往左每 **3 位**一组，不足补 0，每组转 1 位八进制。
- **二 → 十六**：从右往左每 **4 位**一组，不足补 0，每组转 1 位十六进制。
- 反向同理（一位拆成 3 位 / 4 位）。

```
(110101)₂  →  110 | 101  →  (65)₈
(11010110)₂ → 1101 | 0110 →  (D6)₁₆
(D6)₁₆  →  1101 0110  →  (11010110)₂
```

### 1.5 必须记住的速算

- `2¹⁰ = 1024`，`1KB = 1024B`，`1MB = 1024KB`
- `16 = 2⁴`：1 位十六进制 = 4 位二进制
- `8 = 2³`：1 位八进制 = 3 位二进制
- 权值表：2⁰=1, 2¹=2, 2²=4, 2³=8, 2⁴=16, 2⁵=32, 2⁶=64, 2⁷=128, 2⁸=256

### 1.6 初赛常考形式

1. 直接在 二/八/十/十六 之间互转填空。
2. 给一段二进制，问「包含几个 1」「最高位权值是多少」。
3. 问 `n` 位二进制能表示多少个数（=`2ⁿ`）、能表示的最大十进制数（=`2ⁿ−1`）。

## 二、原码、反码、补码

> 计算机内部用**补码**存储整数。这三者只在「有符号整数」「负数表示」上有区别。

### 2.0 机器数的概念

> **真值**：人理解的数值（如 −5、+12）
>
> **机器数**：计算机实际存储的二进制串（受位数限制）
>
> **位数**：规定了机器数的长度，如 8 位机的机器数只有 8 个二进制位

**具体例子**：

用 8 位来存 `+12` 和 `-12`：

| 概念 | 说明 | +12 | −12 |
|------|------|-----|-----|
| **真值** | 数学上的数值 | `+12` | `−12` |
| **机器数（原码）** | 符号位 + 数值位的二进制 | `0000 1100` | `1000 1100` |
| **机器数（补码）** | 计算机实际存储的形式 | `0000 1100` | `1111 0100` |

注意上表：`+12` 的原码和补码相同，`−12` 则不同——因为计算机内部存的是**补码**。

### 2.1 机器数的结构（以 n 位为例）

- **最高位 = 符号位**：`0` 表示正，`1` 表示负。
- 其余 `n−1` 位 = 数值位（真值的二进制）。

### 2.2 原码

- 正数：符号位 `0` + 真值二进制。
- 负数：符号位 `1` + 真值二进制。
- 例（8 位）：`+5 → 0000 0101`；`-5 → 1000 0101`

缺点：`0` 有两种表示（`0000 0000` 与 `1000 0000`），且加减要分正负判断。

### 2.3 反码

- 正数：与原码相同。
- 负数：**符号位不变，数值位按位取反**。
- 例（8 位）：`-5` 反码 = `1111 1010`

### 2.4 补码

- 正数：与原码相同。
- 负数：**反码 + 1**。
- 例（8 位）：`-5` 补码 = 反码 `1111 1010` + 1 = `1111 1011`

### 2.5 为什么计算机用补码

1. **减法变加法**：`a − b = a + (补码表示的 −b)`，一套加法电路搞定加减。
2. **0 只有一种表示**：`0000 0000`，没有「±0」歧义。
3. **表示范围比原码多一个数**。

### 2.6 表示范围（n 位有符号整数，补码）

```
最小值 = −2^(n−1)        最大值 = 2^(n−1) − 1
8 位：  [−128, 127]
16 位： [−32768, 32767]
32 位： [−2³¹, 2³¹−1]
```

> 易错：`−128` **没有对应的原码和反码**，只有补码 `1000 0000`。这是补码比原码多表示一个负数的原因。

### 2.7 由补码求真值（两步法）

- 符号位为 `0` → 正数，直接按权展开。
- 符号位为 `1` → 负数，对补码**再求一次补**（取反 + 1）得到绝对值，再加负号。

```
补码 1111 1011
符号位 1 → 负数
取反+1：0000 0100 + 1 = 0000 0101 = 5
真值 = −5
```

- 快速求负数的补码/源码：从右往左找第一个1，其和右边不变，左边直到符号位全部取反

~~~
原码：1100 1010
            ↑ 第一个1，右边不变，左边取反(符号位除外)
补码：1011 0110
~~~

## 三、位运算（Bitwise）

> C++ 中位运算直接操作整数的二进制位(是机器数中的补码形式)，是初赛和复赛的高频考点。

### 3.1 六种运算符

| 运算符 | 名称 | 规则 |
|--------|------|------|
| `&` | 按位与 | 对应位**都为 1** 才得 1 |
| `|` | 按位或 | 对应位**有 1** 即得 1 |
| `^` | 按位异或 | 对应位**不同**为 1，**相同**为 0 |
| `~` | 按位取反 | 0 变 1，1 变 0（包括符号位） |
| `<<` | 左移 | 全体左移 k 位，低位补 0（等价 ×2ᵏ） |
| `>>` | 右移 | 全体右移 k 位（等价 ÷2ᵏ 向下取整） |

```
5 & 3 :  0101 & 0011 = 0001 = 1
5 | 3 :  0101 | 0011 = 0111 = 7
5 ^ 3 :  0101 ^ 0011 = 0110 = 6
~5(8位): 0000 0101 → 1111 1010 (= 补码表示的 −6)
5 << 1 : 0101 → 1010 = 10  (×2)
6 >> 1 : 0110 → 0011 = 3   (÷2)
~0 : -1
~(-1) : 0

左移，右边补0
右移，左边补符号位

你觉得想不到：负数一直右移，最终只会变成-1，想一想为什么？
非负数 一直右移 会变0
负数 一直右移 会变-1
```

### 3.2 异或（^）的重要性质

- `a ^ a = 0`
- `a ^ 0 = a`
- 交换律：`a ^ b = b ^ a`
- 结合律：`(a ^ b) ^ c = a ^ (b ^ c)`
- 应用：**不用临时变量交换两个数**

```cpp
a ^= b;   // a = a^b
b ^= a;   // b = b^(a^b) = a
a ^= b;   // a = (a^b)^a = b

还可以写成：a^=b^=a^=b
```

### 3.3 取位 / 置位 / 清位 / 翻位的模板，以及常见位运算操作

设 `k` 从 0 开始编号（最右是第 0 位）：

```cpp
取第 k 位      : (x >> k) & 1
把第 k 位置 1  : x | (1 << k)
把第 k 位置 0  : x & ~(1 << k)
把第 k 位翻转  : x ^ (1 << k)
取低 n 位      : x & ((1 << n) - 1)
判断奇偶       : (x & 1) == 1  → 奇数
```

**综合示例**：对 `x = 13`（二进制 `1101`）进行操作

| 操作 | 代码 | 结果（二进制） | 结果（十进制） |
|------|------|---------------|---------------|
| 取第 2 位 | `(13 >> 2) & 1` | `0011… & 1 = 1` | `1` |
| 把第 1 位置 1 | `13 \| (1 << 1)` | `1101 \| 0010 = 1111` | `15` |
| 把第 0 位置 0 | `13 & ~(1 << 0)` | `1101 & 1110 = 1100` | `12` |
| 翻转第 3 位 | `13 ^ (1 << 3)` | `1101 ^ 1000 = 0101` | `5` |
| 取低 2 位 | `13 & ((1 << 2) - 1)` | `1101 & 0011 = 0001` | `1` |

常见操作

~~~
x & x = x
x | x = x
x ^ x = 0

x & 0 = 0
x | 0 = x
x ^ 0 = x

'A' ^ 32 = 'a'
'a' ^ 32 = 'A'

'A' | 32 = 'a'
'a' & (~32) = 'A'
~~~



### 3.4 运算符优先级（初赛必考易混）

从高到低（节选中与本题相关的）：

```
~  (按位取反)
算术:  *  /  %  +  -
移位:  <<  >>
关系:  <  >  <=  >=  ==  !=
按位:  &  高于  ^  高于  |
逻辑:  &&  高于  ||
赋值:  =  +=  ...
```

> 关键易错点：**位运算整体低于算术和关系运算**；`&` 高于 `^` 高于 `|`；`&&` 高于 `||`。
> 例：`3 + 5 & 1` 先算 `3+5=8`，再 `8 & 1 = 0`。

## 四、逻辑运算

### 4.1 三种逻辑运算符

| 运算符 | 名称 | 结果 |
|--------|------|------|
| `&&` | 逻辑与 | 两边都「真(非0)」才为真 |
| `||` | 逻辑或 | 有一边为真即为真 |
| `!` | 逻辑非 | 取反 |

- 操作数是「真假」概念：`0` 为假，非 0 为真。
- 结果类型是 `bool`，在 C++ 中 `true` 当作 `1`、`false` 当作 `0`。

### 4.2 短路求值（重点中的重点）

- `a && b`：若 `a` 已经为假，**`b` 不再计算**。
- `a || b`：若 `a` 已经为真，**`b` 不再计算**。

```cpp
int x = 0;
if (x != 0 && 10 / x > 2) { }   // 安全：x==0 时右边不执行，不会除零
```

> 初赛常出题：「以下代码是否会崩溃 / `b` 是否会执行」——核心就是看左边是否已能决定结果。

### 4.3 逻辑运算 vs 位运算（经典易错对）

```
1 && 2  = 1 (两边都非0 → 真)
1 &  2  = 0 (二进制 01 & 10 = 00)
1 || 2  = 1
1 |  2  = 3 (01 | 10 = 11)
!5      = 0
~5      = ... (按位取反，得到补码形式的负数)
```

> 记住：`&&  ||` 看「真假」，返回 0/1；`&  |` 看「每一位」，返回按位结果。

### 4.4 习题一个

~~~C++
int x = 1, y = 1, z = 1;
if(x ++ <  ++ y || ++ z){
    x ++ ,y ++, z ++;
}
else{
    x = -1, y = -2, z = -3;
}
// 三个变量的大小
~~~

> 注意逻辑惰性

## 五、lowbit

### 5.1 定义

```
lowbit(x) = x & (-x) 
```

含义：取出 `x` 的二进制表示中，**最低位的一个 1 及其后面所有 0** 所组成的数值。

### 5.2 原理（为什么 `x & (-x)` 能取到最低位 1）

`-x` 在计算机里是 `x` 的**补码**（按位取反 + 1）。取反后，最低位 1 右边本来全是 0 → 取反后全变 1；左边全部取反。再 +1 会把这一串低位的 1 进位，恰好只保留住原来的最低位 1，其余位变 0。于是 `x & (-x)` 仅该位为 1。

```
x    = 12 = 0000 1100
~x        = 1111 0011
-x = ~x+1 = 1111 0100   (= -12 的补码)
lowbit(12) = 1100 & 0100 = 0100 = 4
```

### 5.3 常见应用

1. **统计二进制中 1 的个数**：不断 `x -= lowbit(x)`（或 `x &= x-1`），计数到 0。
   ```cpp
   int cnt = 0;
   while (x) { x -= lowbit(x); cnt++; }   // 或 x &= (x-1);
   ```
2. **判断 x 是否为 2 的幂**：`(x & (-x)) == x`（且 `x != 0`）。

### 5.4 一组配套位技巧

```cpp
lowbit(x)      = x & (-x)     // 取最低位 1 的值
X & (-x)	   = 只保留最低位的 1
x & (x - 1)    = 消去最低位的 1
x ^ (x - 1)    = 最低位 1 及以下全变 1
x & (~(x - 1)) = 等价于 lowbit(x)
__builtin_popcount(x)  // C++ 内置：返回 x 中 1 的个数
```

## 六、初赛高频易错清单（考前再过一遍）

1. `&` 与 `&&`、`|` 与 `||` 的区别（真假 vs 按位）。
2. 负数用补码存储；`-128` 没有原码/反码。
3. 补码求真值：符号位 1 时「再求一次补」。
4. `<< k` = ×2ᵏ，`>> k` = ÷2ᵏ（向下取整）。
5. 逻辑短路：左边已能定结果，右边不执行。
6. 位运算优先级低于算术/关系；`& > ^ > |`；`&& > ||`。
7. `lowbit(x) = x & (-x)`，可判断 2 的幂、数 1 的个数。
